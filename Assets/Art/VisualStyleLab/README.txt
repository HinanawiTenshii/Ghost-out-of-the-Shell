VISUAL STYLE LAB / 视觉实验街区

打开场景：Assets/Scenes/Experiments/VisualStyleLab.unity
这是独立实验场景，不在正式 Build Settings、选关菜单或 Level2 关卡组中。
不修改 Level2-Floor1，也没有通往正式关卡的传送点。

取材：城镇一层 (-84, -29) 附近商铺。
沿用商铺的地面、16 件家具与原始布局、侧门及玻璃。
周边重新组织为紧凑街道，补充水道、灯、树、可破坏灌木和机关。
当前已应用第 2 项视觉试验：墙壁、地面与道路的空间感。
配色采用与 AZURE QUEST 假标题及终端真标题兼容的深蓝地面、浅灰蓝石材墙壁；
保留家具、灯具的原有暖色，不为普通墙体和地面新增发光效果。
墙体整体保持明亮、低饱和，相连墙段按合并后的轮廓绘制亮边、暗边与斜向转角，
不再逐块叠加边缘；贴地阴影也按整体轮廓去重。接缝间距由 2.6 增至 4.2，
宽度由 0.035 减至 0.02，颜色接近墙面底色，取消亮色接缝端头并避开交接处。
室内为低对比错缝石板。道路为贴地大块铺石，去除亮暗路缘与外侧投影，
接缝变细变淡、取消石板亮边，交叉路口保持连通；桥面沿用可通行位置。
原有碰撞、对象位置、AI、机关绑定、UI、摄像机与 CRT 参数均未改变。

第 4 项视觉试验：角色与场景物件（不添加控制角色识别轮廓）。
- 5 名实体角色添加克制的脚下接触阴影，共用网格与材质；幽灵不添加。
- 阴影跟随根节点而非奔跑的视觉起伏；隐藏身体、灵体化或死亡时关闭。
- 角色仍使用原像素造型、点采样和动画，只在本场景调整头饰、服装、金属色阶。
- 工程师护目镜与工具保留识别色，但不普遍增加发光或描边。
- 桌椅、圆桌和弧形柜台使用暗侧面、暖木边框、低饱和蓝灰台面；左上方向受光。
- 炼药锅外壳降低高亮，液体状态颜色与原有气泡不变。
- 20 件家具及机关、8 件室外装饰增加贴地阴影，装饰子节点随所属对象加载、卸载。
- 当前静态角色/物件阴影及亮边网格共 1004 顶点，角色阴影复用；不新增实时灯或全屏效果。
- 只有角色阴影组件进行轻量可见性检查，不每帧搜索对象或生成网格。
- 不修改正式角色/家具预制体、攻击与移动更新频率、CRT 或视野覆盖参数。

停用通用包围亮边，用原有明亮椅背、扶手与较暗座面恢复辨识度，不修改形状、位置或尺寸。
室外修订：树与灌木用较克制的三档绿色；木桶与告示牌使用统一暖木色；
花坛保留土壤与石边分层；路灯仅调整金属与底座阴影，原有光色、光强及动态不变。
原有水流、道路、权限区域、机关状态指示与碰撞不变。
机关边缘修订：拉杆、水闸控制器、电池槽与炼药锅使用贴合可见底座的柔边接触阴影，
不再沿碰撞盒外挤出硬边；拉杆阴影只覆盖底座而非上方把手的碰撞范围。
拉杆的三段状态指示移入底座内，避免悬在物件下方。所有原有碰撞和功能均保持不变。

第 5 项视觉试验：水域、植物与环境动态。
- 树冠每约 8 秒短暂轻摆，灌木采用错开的摆动相位；每秒更新 8 个装饰姿势。
- 树干、枝干、灌木根节点及所有碰撞箱固定不动；禁用组件会还原原有视觉。
- 河道改为深蓝水面与稀疏、断续的浅青亮纹，沿原有水流方向运动；继续跟随水闸淡入淡出。
- 路灯缩小光晕、降低亮度及呼吸幅度，不增加全场呼吸或新的实时灯。
- 该实验街区没有沙漠和独立水池，不额外添加沙尘或水池来改变场景布局。

第 6 项视觉试验：视野与机关状态。
- 普通视野填充 alpha 为 0.065，以约 1.1 像素的细边界保持可读性。
- 警告/怀疑改为琥珀色，敌对为红色，搜索为较淡的琥珀色。
- 复用 AI 原本的动态视野网格，只增加 UV/显示材质，不增加判定射线或修改感知参数。
- 延续原有 stencil 去重：重叠处只显示一层，敌对优先于警告及普通状态。
- 电池槽、水闸控制器、水闸和拉杆增加三小段指示光：待机稳定、工作逐段亮起、完成短闪、断电熄灭。
- 电池接线复用原有电流光带，缩短亮段并降低亮度；外壳不新增泛光。
- 显示组件只读取已有状态，不操作机关、不耗电、不改变权限、交互或存档规则。
- 树冠网格与叶片位置使用缓存；状态灯约 12.5 Hz 更新，只有 12 顶点；屏外延后装饰上传。
- 场景加载/卸载、暂停和组件禁用均可正常恢复；没有新增全屏后处理。

方案八：HUD / 窗口终端风格（只在本测试场景启用）
- 00_Systems 挂载 VisualStyleLabTerminalPresentation；正式关卡与标题界面不受影响。
- 普通边框降低亮度；主窗口、物品栏、小地图与权限框用短促的青白角标点亮。
- 窗口为近不透明的深蓝底，正文使用清晰的浅青色；只有标题和角标使用额外光晕。
- 保留生命/盾牌/警告、禁用选项、技能与物品图标的语义颜色，不扩大图案轮廓。
- 暂停、任务/地图、物品说明、阅读、对话、属性、存读档窗口使用统一分层。
- 主窗口打开约 0.23 秒：角标先出现，背景分段展开，正文短促显现；不缩放字体。
- 切换页签、选任务、折叠子任务、滚动说明、更新正文不重播开窗动画。
- 保留已追踪任务的亮底、选中任务的粗边框，以及原有鼠标/键盘反馈和信息悬停逻辑。
- 小地图与菜单地图仅降低墙体/地面亮度；玩家与紫晶任务标点不改变。
- 使用 uGUI 自有图形注册表增量处理，无逐帧场景查找，不强制刷新地图缓存。
- 禁用实验组件/离开场景时，会清理新增角标与染色，并恢复常驻 HUD/窗口原有光晕策略。
- 实验说明牌补齐 UI 字体，说明精简以适配原有阅读区域（原先为空字体，会显示空白）。
- 不增加 HUD 常驻文字，不新增全屏滤镜，不改变窗口输入、游戏状态或存档规则。

整体提亮配色（仅测试场景）
- 参考假标题的蓝青明暗层次和真标题的青白高光，提亮对象中间色，保留深色接触阴影。
- 家具、植物、角色服装、炼药锅和拉杆等主体适度提亮；木色、肤色和植物绿保留原有色相。
- 地面、道路与水面提亮幅度低于家具；原本明亮的浅灰蓝墙壁只微调，接缝同步处理。
- 仅修改本场景的 171 项颜色与 12 个已有装饰网格的顶点色；不改形状、透明度、碰撞、状态提示色或 CRT 参数。
- 不增加灯光、泛光轮廓、Draw Call 或逐帧染色脚本；正式场景、共享预制体不受影响。
- Tools/ApplyVisualStyleLabBrightPalette.cs 只能对隔离副本中的指定基线应用一次，防止重复提亮或覆盖后续手动编辑。
- 运行回归通过 208 项检查，含家具、植物、角色配色，以及机关、视野、UI 和原有接缝/阴影检查。
