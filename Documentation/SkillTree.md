# 角色能力技能树

- Tab 菜单 → 角色能力。左键选择节点，长按升级按钮 1.2 秒购买；松开、移出按钮或关闭页面会取消进度。
- 右侧支持鼠标滚轮、加减按钮缩放（50%–300%），左键拖动及横纵滚动条平移。
- 生命强化消耗 2 个收集物，只能购买一次。当前及以后附身的非幽灵角色获得最大生命与当前生命各 +1；同一个角色反复附身不会重复获得加成。
- 两个锁定节点不可选择，购买生命强化后仍保持锁定。
- 收集物与技能解锁 ID 保存在 PlayerGrowthAttributes.RuntimeState；每个角色获得的加成保存在 ZeldaCharacterData.RuntimeState.appliedHealthBonus。

## 扩展入口

在 PlayerGrowthAttributes.Skills 添加 SkillDefinition：稳定 id、标题、说明、消耗、锁定标记、节点坐标、父节点 ID 以及 healthBonus。页面自动创建节点与连线。

增加新的效果类型时，扩展 SkillDefinition 和 TryUpgradeSkill/对应角色效果应用方法；保持已发布的技能 ID 不变以兼容存档。当前心形图标及锁图标由 SkillPageArt 绘制，可在此增加图标类型。

## 游戏内验收

1. 无选中项时说明为空；锁定节点点击无反应。
2. 收集物不足 2 时升级按钮不可用；数量变化后刷新。
3. 长按不足 1.2 秒松开不扣费；完成后仅扣 2 个，节点变浅且按钮显示已升级。
4. 暂停时动画、拖动、缩放和长按计时正常。
5. 附身不同角色各获得一次加成，反复切换同一角色不重复加血。
6. 保存、跨场景、读取旧/新存档后检查数量、技能状态与生命值。
