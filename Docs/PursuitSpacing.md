# 追击角色间距与超越

追击同一目标、行进方向相近的敌对角色，现在使用基于碰撞体尺寸和实际移动速度的局部避让。

- 等速或较慢的后方角色在接近前方角色时调整速度，保留少量间距。
- 较快的角色提前检查侧向空间，绕过较慢的角色；会检查墙体和第三名角色，不会关闭碰撞。
- 超越方向保持到整个身体越过前方角色，避免左右反复切换。通道不足时保持跟随，不把等待误判为寻路卡死。
- 同排过近的角色由其中一方侧移，保留单一让行方。
- 原有 A* 绕墙、接敌攻击、共用敌对/搜索计时不变；避让沿用错峰刷新，不为每个移动角色额外重建路径。

所有使用 `ZeldaCharacterAiBase` 的角色自动使用此功能，无须逐个修改预制体。

Inspector 中 `Pursuit Spacing` 参数：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| Pursuit Spacing | 0.16 | 碰撞体与原有避让余量之外增加的间距（世界单位） |
| Pursuit Look Ahead Time | 0.7 | 按自身速度计算的前瞻时间（秒） |
| Pursuit Overtake Speed Advantage | 0.15 | 尝试超越移动角色所需的最小速度优势 |

回归测试：`Tools/PursuitSpacingSmoke.cs`，在隔离 Unity 工程中运行 `PursuitSpacingSmoke.Run`。包括稳定超越、等速跟随、墙边换道、窄通道、静止角色、第三人占道、体型缩放、六人追击与跨场景隔离。
