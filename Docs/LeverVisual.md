# 拉杆像素外观

统一修改 `LeverData.CreateLeverSprite`，所有使用该脚本的现有场景拉杆及 `Assets/Prefabs/GroundLever.prefab` 在运行时使用新外观，无需替换或重新绑定机关。

- 原半圆底座改为方形木质底座、钢灰顶盖与方形轴座。
- 灰色杆身收细为 3 像素宽外轮廓、1.5 像素宽内层；红色握柄采用削角像素圆头和底部暗面，保持原中心与 6×6 外接尺寸。沿用当前人物/道具的简洁像素块，不添加细碎纹理。
- 原 `baseColor`、`leverColor` 及场景覆写继续有效；增加 `metalColor` 调整金属主体颜色。
- 开关姿态精确左右镜像。保留 24×24 画布、26.666667 PPU、原枢轴及握柄中心 (17,20)/(7,20)，不改变机关人偶挂接点。
- 不改场景、预制体位置/缩放、碰撞、E 交互、复杂度、存档、地图图标或机关绑定。
- 仍为一个渲染器、两张初始化生成的精灵；禁用 mipmaps，销毁时释放本对象拥有的精灵和纹理。无需新增子物体或动画脚本。

`Tools/TestLeverVisual.ps1` 执行实际绘制代码，检查轮廓连通、镜像、握柄中心、尺寸及碰撞/挂点不变，并生成 `Docs/Lever-preview.png`。预览不含 Unity 的 CRT 后处理，编辑器非运行状态仍沿用原先的显示机制。
