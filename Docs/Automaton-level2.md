# Level 2 自动人偶

预制体：`Assets/Prefabs/Level2NPCS/Automaton-level2.prefab`。

## 外观与战斗

16 PPU、16×20 像素画布的人形机械体，沿用巨兽的灰钢装甲、深灰关节、
规则红色能量装甲与少量金色眼部。双手是与前臂一体的剑刃，非持剑的人手。
四方向各有待机、两帧行走和攻击姿态。正背面显示双剑手，侧面只露出近侧一把，
远侧剑及插座被躯干遮住；行走时同样保持单剑轮廓。
攻击时移除静止剑手，TwinBlades 特效按朝向显示双刃或侧面单刃，避免重复手臂。
一个共享攻击判定，同次攻击不会双倍伤害。
蓝色编辑器边框、碰撞、附身、受伤和死亡反馈沿用当前角色系统。

预制体根节点 XY 缩放为 0.85，视觉和身体碰撞同比缩小 15%。待机可见高度
为 0.85 世界单位，小于圣骑士的 0.9625（14 像素 / 16 PPU × 1.1），约低 12%。
攻击距离、伤害、视野半径和 AI 参数不随这次外观调整改变。

默认生命 10、攻击 2、移动速度 3.2、攻击时长 0.32 秒；可在 Inspector 调整。

## 行为

- 默认待机，完全静止，不巡逻、不受角色分离或墙体推开算法影响。
- 待机视野使用普通角色的蓝色；激活敌对后切换为原有红色，停机恢复蓝色。
  颜色跟随持久化激活状态，读档/重新加载后保持正确，临时眩晕不会误变回待机蓝色。
  Inspector 的 Idle Vision Color 控制待机色，基础 Vision Color 保留敌对色。
- 激活后保持敌对；以 7 单位半径、360° 圆形视野发现角色，沿用墙体遮挡。
  优先持续攻击当前可见目标，无目标时选最近可见的存活角色。玩家和 NPC
  都可成为目标，但排除同类自动人偶（武装魔像）；NPC 的玩家移动组件关闭不再使其被忽略。
- 目标离开视野、死亡或隐藏后重新选择；无目标时原地等待，但不会自行取消激活。
- 各类普通 NPC 看见已激活且非玩家控制的自动人偶后，将其视为公共敌人并攻击，
  不受权限等级/职业限制。人偶被玩家接管、停机或死亡后取消公共敌人身份。
  未激活的人偶不会因此启动；同类自动人偶之间不会主动索敌，无论对方待机、激活、
  AI 被禁用或由玩家控制。通过 AI / 角色数据类型识别，不依赖名字、权限或颜色。
  旧目标或读档恢复的同类目标会被清除并取消攻击；只剩同类时保持敌对激活、原地等待。
  本规则只修改 AI 目标选择，不给同类添加伤害免疫，也不限制玩家手动攻击。
- 行为状态只有待机/敌对，不调查、不警告、不搜索或返回出生点。
  眩晕和附身锁仍是临时控制效果；王命不会令机器进入第三种行为状态。
- 尊重已有幽灵/隐身的不可探测及不可攻击规则，不凭空给无攻击能力的角色增加攻击。

## 待机拾取 / 武装魔像

- 靠近、面向待机魔像时，沿用统一交互系统显示“按[E]拾取”。敌对、死亡、正被附身或玩家控制中的魔像不可拾取。
- 检查当前操控角色的 `FinalAttackPower`（属性面板力量，含强化）；力量至少为 3 才能拾取。
  不足时显示“太重了，以当前的力量无法举起”。满物品栏不会移除场景角色。
- 物品名称：武装魔像。
- 物品说明：尚在研发中的武装魔像，目前索敌仍存在故障，启动后会攻击目光所及的所有人。
- 每只占一个独立栏位。R 与 Q 均在当前角色脚下放回待机魔像，不会直接激活，也不会被附近纸箱收纳逻辑截获。
  放置无需再次检查力量；重新拾取仍需力量达标。放置后有 0.35 秒防误拾取延迟。
- 保留独立物品 ID、剩余生命、角色属性、外观颜色、AI 配置、大小及朝向。库存快照、PlayerPrefs 和场景/磁盘存档均传递角色物品状态。
- Resources/PickupItems/ArmedGolemPickupItem 是原 Automaton-level2 的预制体变体，不维护第二份人物外观。
  物品图标使用角色正面姿态，原角色碰撞箱、大小、视野和攻击功能不变。
- `Tools/TestArmedGolemPickup.ps1` 执行 30 项拾取、力量边界、R/Q、状态及失效数据保护检查；Unity 物理、生命周期与 JSON 服务使用桩，仍需 Play Mode 验证。

## 外部条件接口（保持不变）

组件 `AutomatonCharacterAi` 提供 UnityEvent 可用的公开方法：

```csharp
automaton.ActivateHostility();       // 条件达成时调用
automaton.DeactivateHostility();     // 显式停机，恢复待机
automaton.SetHostilityActive(true);  // 带 bool 的事件/脚本接口
bool activated = automaton.HostilityActivated;
```

未绑定任何具体任务、拉杆、区域或计时条件；将激活方法连接到实际关卡条件即可。
受伤、目击附身、毁门、权限区域和调查事件不会自动激活它。
重复调用是幂等的。可在运行时组件菜单中使用 Activate/Deactivate 测试。
激活标记进入既有 AI 存档；读档、跨场景返回和加载开关不会把已激活机器误重置为待机。
