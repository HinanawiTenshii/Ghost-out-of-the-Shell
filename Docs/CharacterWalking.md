# 简单角色行走动画

使用与圣骑士相同的两帧交替抬脚思路，保持当前像素精灵、四向朝向、颜色及攻击姿态。圣骑士继续使用其已有动画，不叠加第二套。

- 剑士及 Warden、LegendaryGuardian 等共用剑士数据的变体：交替抬起短靴。
- 平民、囚犯、铁匠、壮汉：仅在各自腿部区域抬脚，不挪动身体、武器或碰撞。
- 贵族与国王：交替提起长袍下摆与鞋子，幅度为一像素。
- 巨兽：活塞腿交替抬起一像素，节奏略慢。
- 幽灵：不接入行走动画，移动保持平移，保留原有朝向、透明与粒子表现。

玩家与 AI 视觉入口统一调用 `ApplyCharacterVisualWithMovement`。只有移动且非攻击、非死亡时播放；停止或攻击时先恢复原方向精灵。使用受游戏时间缩放影响的计时器，暂停不推进，重复刷新同一帧也不会加速动画。

`PixelCharacterWalkAnimator` 在首次移动时自动挂载，无需逐一修改关卡和预制体。每个方向只生成并缓存两张精灵，不在每帧生成纹理，角色销毁时释放。五种此前释放 CPU 像素的角色保留其待机小纹理的可读数据，用来生成行走帧；攻击贴图仍按原规则释放。坐标、碰撞器、移动速度和能力数值不变。

新增角色需要在 `Supports` 和 `Initialize` 中明确配置脚部像素区域。未知角色默认不进行变形。

验证：`Tools/TestCharacterWalking.ps1` 编译并运行实际像素变形函数（以轻量类型替身替代 Unity 数据结构），检查各体型、上下边界、幽灵排除规则及接入点；仍需在 Unity 内检查移动、附身、眩晕和暂停的最终视觉效果。
