# 锁住的门：地图标记

- 现有 `DoorHingeInteraction` 门自动挂载运行时 `LockedDoorMapMarker`，无需逐个修改预制体或场景。仅采集属于该门的 `DoorData` 门板，不为共用转轴脚本的桥梁生成图标。
- 门处于锁定、门板完好状态，且第一次进入当前玩家的真实视野及摄像机画面时发现。每 0.15 秒检查一次视野；使用门板范围而不是转轴位置判定。隔墙、视野遮罩外或加载存档期间不会发现。
- 小地图和 Tab 地图使用同一条门板颜色的粗线，位置、方向、长度按实际门板变换计算；双开门合并为一条线。远景缩放时保留最小宽度、长度保证可辨认。
- 发现后离开视野、距离卸载、切换场景均保留。使用现有地图兴趣点存档保存发现状态、位置、朝向与颜色；旧存档没有新数据时从首次看见开始记录。
- 钥匙、密码、撬锁或事件解锁时隐藏；任意门板被破坏时立即隐藏。重新锁住已发现且完好的门时再次显示。
- 标记不可点击选中，不生成额外场景精灵或碰撞体，不更改门的交互、转动、判定范围。
- 在 Tab 地图上悬停粗线，会像拉杆一样显示仅包含「锁住的门」的名称提示；移开、门解锁或门板破坏后消失。透明悬停区域随地图缩放、平移和门板朝向更新，不重复绘制图标，也不支持点击标记。

验证：`Tools/TestLockedDoorMap.ps1`、`Tools/TestLeverMapDiscovery.ps1`、`Tools/TestLeverMapHover.ps1`、`Tools/TestMiniMapBridge.ps1`。编译补充清单为 `Tools/LockedDoorMap.Validation.targets`。仍需 Unity 实际运行检查不同大小门在小地图上的视觉效果。
