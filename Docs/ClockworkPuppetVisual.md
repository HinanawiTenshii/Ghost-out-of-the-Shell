# 机关人偶：粗像素噬菌体

修改 `ClockworkPuppetPickupItemVisual.cs`，拾取物、背包图标与部署人偶共用同一套 24×28 像素图案（原为 37×43）。延续炸弹道具的点过滤、大色块和少量明暗层次，使用四档冷灰金属色和两档红色能量色，移除多重描边、细碎高光和过密关节细节。

保留噬菌体的多面体头部、细长分节尾鞘、底盘、中央刺针以及四条弯折抓脚。每条支脚从底盘先向上伸至关节，再向外、向下弯折落地，恢复原本的抬膝轮廓。支脚为两像素宽金属条，轮廓对称，切面光照略有左右差别；脚底位置、画布和其他部位不变。

尾鞘保留六段剩余能量显示，每段两像素；能量耗尽时由红色变为暗灰，补满时恢复。运行时仅在可见能量档位或腿部姿态变化时更新贴图。

部署后实际移动时，两组对角支脚以每帧约 0.12 秒交替抬起两像素，关节同时抬起一像素；根部、头部、底盘和刺针不动。维持先向上再向下弯折的造型。静止时四脚落地，拾取物与背包图标不播放步行动画。遥控和自动寻路共用实际位移检测，碰墙无位移时停止；用 0.06 秒余量衔接物理帧，释放输入、附着机关、退出遥控或打开阻塞界面时立即恢复静止。忽略传送级位移，暂停及重新启用不触发虚假步行动画。

三个姿态的像素图只初始化一次，部署人偶复用同一 Sprite 和 Texture，不在每个渲染帧分配资源。换帧后会重新应用当前能量，避免步行导致能量条恢复满格。

不修改预制体 GUID、拾取/部署缩放、碰撞箱、道具属性、遥控、寻路、附着机关、开锁、回收、存档和能量消耗逻辑。部署精灵仍为一单位高，锚点 `(0.5,0.04)`。

`Tools/TestClockworkPuppetVisual.ps1` 使用轻量 Unity 数据桩执行正式像素生成代码，检查完整连通性、四只独立脚、轮廓对称、拾取/部署一致及全部能量档位；生成 `Docs/ClockworkPuppet-preview.png`（不含 CRT 后处理）。Unity API 编译通过；未进行游戏内操作实测。

`Tools/TestClockworkPuppetWalk.ps1` 额外执行正式 LateUpdate/重置代码的移动门控测试，检查三种姿态与全部能量档位、交替抬脚、连通性、恢复静止无残影，输出 `Docs/ClockworkPuppet-walk-preview.png`。物理位移使用测试桩，不代替游戏内遥控实测。
