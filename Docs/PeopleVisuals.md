# 平民、囚犯、贵族与国王重绘

沿用当前角色的 16×16 像素规格：四向独立外观，头部直接衔接衣领/肩部，没有脖子；左右侧面镜像，手部位于躯干中部。保持既有像素密度、预制体引用、属性、碰撞、AI 和技能。

- 平民：短发、翻领短上衣，下半身统一采用原鞋子的深褐色。
- 囚犯：短发茬、粗布短衣、补丁与绳腰带，下半身统一采用原鞋子的深褐色。
- 贵族：梳理过的头发、装饰领、袖口与滚边长袍。
- 国王：继续使用贵族预制体变体，增加三尖王冠、宝石和浅色礼服领；保留当前紫色礼服、金色滚边及发号施令技能。

## 服装换色

在预制体或场景实例的角色数据组件中调整：

- Civilian Zelda Character Data → Configurable Clothing → Clothing Color（上衣）。腿部固定使用原鞋子的深褐色；旧 Trousers Color 数据保留以兼容序列化，但不再参与绘制，并从 Inspector 隐藏。
- Noble Zelda Character Data → Noble Robe Appearance → Robe Color（长袍）、Robe Trim Color（滚边）。

衣服阴影/亮面从主色自动生成，换色不影响头发与肤色。原有序列化字段名称和预制体配色保留。运行时在 Inspector 改色后，下次绘制会同时重建待机、攻击和行走缓存。编辑模式下的改色在下次角色生成外观时应用。

## 动画和检查

平民与囚犯腿部缩短一行像素，鞋子由两行改为一行，行走区域为 x=5..6、9..10，y=3..4。支点 y 从 0.25 改为 0.3125，补偿缩短量，保证世界空间脚底位置不变。贵族/国王的支点、外观和半侧衣摆抬起的两帧动画不变。攻击时先清除同一只手的待机姿态，再画出击手，不叠出额外手臂。

运行 Tools/TestPeopleVisuals.ps1，以生产绘图代码和生产行走变换生成并检查四类角色共 64 个姿态，验证像素连通、无脖子、侧面镜像、攻击手替换和可配置配色；颜色缓存刷新另作源码检查。输出 Docs/People-Idle-preview.png、People-Attack-preview.png、People-Walk0-preview.png 和 People-Walk1-preview.png。

预览不包含 CRT、运行时整体着色或伤害闪烁。最终游戏内视觉效果仍需在 Unity 运行时确认。
