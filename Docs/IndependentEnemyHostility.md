# 独立敌人的仇恨隔离

骷髅和已激活敌对模式的人偶不会成为其他 NPC 对玩家连锁仇恨的来源：

- 玩家被这两类敌人锁定，不会通过“已有其他 AI 对玩家敌对”的轮询传播给旁观 NPC。
- 玩家攻击或击杀这两类敌人，不会触发旁观 NPC 的攻击目击敌意。该规则在致命伤、死亡及昏迷回调期间保持稳定，不依赖敌人当帧是否仍是活跃威胁。
- NPC 仍会正常攻击骷髅和敌对人偶，而不是因此与玩家结盟或停止所有战斗。
- NPC 受到同场景的骷髅或已激活人偶伤害时，无须先看见攻击者便会立即将其设为敌对目标；随后沿用敌对追踪、丢失视野后的搜索与恢复流程。攻击者死亡或人偶停用时结束对此目标的追踪。昏迷、附身锁定等原有保护条件保留。
- 不清除已经存在的其他原因导致的敌意；越权、攻击普通角色、破门、目击 R 放置引燃炸弹等行为保持原有规则。
- 未激活人偶保持此前规则，不在本次敌对人偶豁免范围内。

接口：`ZeldaCharacterAiBase.SharesHostilityWithOtherNpcs`。默认允许传播，骷髅始终关闭，人偶在敌对模式激活时关闭。

验证：`Tools/TestWitnessedAttack.ps1` 覆盖攻击/击杀、即时目击和延迟轮询、普通敌意并存及原有敌意保留；`Tools/TestAutomatonAi.ps1` 验证人偶和骷髅的目标选择不受影响。
