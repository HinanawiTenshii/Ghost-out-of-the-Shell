# 角色对话

## 挂载与编辑

在角色根对象（具有角色数据与 ZeldaFourWayMover 的对象）添加 **Character Dialogue (角色对话)**。也可以在角色数据组件的右键菜单选择「添加角色对话」。组件自带一段问候和退出选项，挂载后即可测试；取消组件勾选或移除组件即可禁止对话，无需修改角色数据脚本。

- 设置「对话显示名称」，留空时使用对象名称。
- 设置开始段落，展开段落填写文字。每个段落 ID 唯一，跳转按 ID 而非列表下标匹配。
- 每段最多四个选项。选项功能为「跳转到下一段」或「退出对话」。下一段通过下拉框选择，可回到之前段落。
- 无选项时自动提供「结束对话」。错误的跳转被禁用，并在 Inspector 提示；Esc 始终可以退出。
- 字体默认使用项目像素字体，可在组件中覆盖；交互距离和背景压暗程度可编辑。

示例：start「有什么需要帮助？」→ 选项「这里是什么地方？」跳转 city；city「这里是沙漠要塞。」→ 选项「再见」退出。

## 游戏内

可对话 NPC 头顶显示几何对话气泡，使用普通世界渲染（不是穿透视野的覆盖 UI）。靠近并面向它按 E，对话气泡在交互选中时变亮、略放大。

同一 NPC 可同时提供 E 对话和 F 附身，不会因出现附身提示而屏蔽对话。实际按住 F 进入附身过程时暂时不能开始对话；对话窗口打开时仍屏蔽附身输入。其他物品、机关保持原本的最近目标优先规则。

幽灵、死亡角色、当前受控角色不能作为交谈对象；玩家幽灵不能发起对话。NPC 处于怀疑 / 警告 / 敌对状态（无论目标是谁）、眩晕或实际附身锁定，或 NPC 正在攻击时，隐藏对话气泡并禁止对话，恢复可对话状态后重新显示。玩家正在攻击、距离过远或中间有实体障碍时也不能交谈；距离不会隐藏正常 NPC 的气泡，方便识别可交谈对象。仅成为 F 附身候选不会隐藏气泡或屏蔽 E 对话。

对话开始时 NPC 朝向玩家，游戏暂停，屏幕右侧显示深蓝色窗口，窗口外变暗，显示鼠标。滚轮查看长文本和历史；点击选项或按 1–4（含小键盘）；Esc 结束。E 不自动选择选项，避免连续按键误选。关闭后恢复原时间倍率和光标状态；退出当帧屏蔽其他交互，避免触发暂停、拉杆或拾取。

窗口四边均有青蓝色边框；NPC 名称与玩家的「你」均独占发言正文上方一行。选项与对话历史分为两个独立区域，中间有分割线；选项区始终停靠窗口底部（操作提示上方），不随对话历史滚动。特别长的选项在底部限高区域内单独滚动，保留上方的对话阅读空间。

禁用 / 移除 NPC 组件、角色死亡、控制角色切换、场景卸载、加载存档都会结束当前对话。每次对话从开始段落开始，不存储对话进度。

## 扩展接口

每个选项可绑定「选择后事件」UnityEvent，调用场景机关或任务对象的公共方法；在继续 / 退出前执行。注意事件发生时场景暂停，使用缩放时间的动画要等对话结束才继续。

需要物品判断、扣除、奖励等带上下文的逻辑时，继承 `DialogueOptionEffect`，将子类组件挂到场景对象，再拖到选项的「扩展逻辑」：

```csharp
public override bool CanSelect(CharacterDialogue speaker, ZeldaFourWayMover player,
    out string unavailableReason) { /* 检查条件；返回 false 禁用选项 */ }
public override bool TryExecute(CharacterDialogue speaker, ZeldaFourWayMover player)
{ /* 执行一次事务；失败返回 false，保留当前段落 */ }
```

选择前再次校验条件，成功后触发 UnityEvent，然后跳转 / 退出。同一帧只执行一个选项，防止快速点击造成重复扣物。条件查询应无副作用。当前未预设任何物品消耗或机关效果。

## 验证

### 对话区域权限

尝试开始对话时，使用当前操控角色的 PermissionLevel 与对话者当前位置的 PermissionArea 比较；同场景重叠区域按最高权限要求处理，禁用或其他场景的区域不参与。
权限不足不会单独隐藏对话图标或 E 交互选项，但按 E 会提示“权限不足，无法进行对话。”，不转动 NPC、不打开窗口、不暂停游戏。
权限等于要求即可对话，未被权限区域覆盖的位置不增加限制；不是比较 NPC 自身的权限等级，也不是检查玩家脚下的位置。
幽灵、距离、遮挡、怀疑/警告/敌对等原有对话资格规则不变。此检查针对开始对话，不额外限制已打开对话中的分支选项。

`Tools/TestCharacterDialogue.ps1` 使用生产方法与轻量 Unity 替身验证分支、事件、退出、交互条件与恢复逻辑；`Tools/TestMenuCursorVisibility.ps1` 覆盖对话在内的菜单光标组合。

编译补充清单：`Tools/CharacterDialogue.Validation.targets`。仍需 Unity Play Mode 人工检查实际字体、视野遮罩、悬停反馈与不同分辨率下的排版。
