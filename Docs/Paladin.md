# 圣骑士

左右侧面头盔已去除面罩前伸像素，目镜与下颌的前缘和额部齐平，不再呈现鸟喙状突出。

头盔正面使用深色 T 形开口（横向目镜与向下延伸的中央竖缝）。四向增加颈甲阴影带，胸甲使用短高光与接缝，避免从头盔到身体贯通的亮色长条；保持原有 16×16 像素色块风格。

预制体 `Assets/Prefabs/Level2NPCS/Paladin.prefab`，角色专属数据脚本 `PaladinZeldaCharacterData` 继承现有 `ZeldaCharacterData`，通用属性仍由 `ZeldaCharacterCommonData` 管理。不修改 SwordGuy 或现有关卡。

配色已降低亮度：铠甲主色与披肩约降低 20%，高光约降低 28%，保持天蓝色倾向、T 形目镜和颈甲分界。脚本默认颜色与预制体序列化颜色同步更新，不改变角色数值。

外观沿用 SwordGuy 的 16×16 色块画法、短腿比例、16 PPU 与 `(0.5, 0.25)` 枢轴，不使用整圈深色描边或高分辨率分节腿甲。天蓝色板甲、全包覆头盔与深色目镜缝，宽肩甲与胸甲形成厚重轮廓。正面左侧蓝色披肩，背面与侧面随朝向呈现对应位置，不露出皮肤。四向精灵使用 Point 采样；两帧交替步行和四向出手姿态，帧资源按需缓存并在销毁时释放。Inspector 可分别调整铠甲、阴影、高光、披肩、目镜色与步行频率。

沿用 SwordGuy 的刚体、碰撞、AI、附身控制、死亡幽灵与剑攻击结构。默认生命 6、力量 1、技巧 1、权限 0、E.G.O 3、附身需求 1、速度 3.5，摄像机 Size 7、视野 13。没有额外添加角色技能。默认是可附身的非玩家角色，拖入场景后运行即可使用。

手部使用封闭式金属护手：正背面露出未被披肩覆盖的一侧，右侧面护手位于躯干中部，左侧面仅在披肩下缘露出少量指尖。护手颜色由铠甲高光派生，高级圣骑士自动使用淡金色。攻击姿态替换待机护手，不叠加两只同侧手；行走抬脚也保持在披肩下方。不改变碰撞、尺寸与战斗数值。

`Tools/GeneratePaladinPreview.ps1` 执行实际绘图方法，校验四方向共 16 个姿态的连通性、披肩遮挡与攻击手部替换；支持 `-PrefabPath` 读取对应配色、`-Pose 0..3` 输出待机/两帧行走/攻击预览。`Docs/Paladin-preview.png` 是静态外观预览，不包含 CRT 滤镜。
