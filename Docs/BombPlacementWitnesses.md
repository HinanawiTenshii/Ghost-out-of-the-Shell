# 目击放置炸弹

仅当玩家成功通过物品栏 R 在场景中直接放置引燃炸弹时，向场景 AI 发送一次放置事件。普通和超级炸弹都适用。Q 丢下炸弹、R/Q 将炸弹放进纸箱、其他物品、失败操作、加载存档以及连锁引爆不会触发。

同场景的非敌对 NPC 必须当时能看见玩家（沿用视野角度、距离、遮挡和隐身判断），才会以现有敌对追踪逻辑攻击玩家。已有敌对状态不刷新目标、攻击周期或追踪记忆。昏迷、附身锁定、暂停感知、玩家控制身体及未激活自动人偶保留现有例外。

放进纸箱的炸弹不会触发 Idle 炸弹躲避，也不会因放入的动作引发敌意，即使 NPC 当时看见玩家。R 放入后仍保持引燃，Q 放入仍保持安全存放。之后才看见炸弹不会追溯本次放置者。

验证：`Tools/TestWitnessedAttack.ps1`、`Tools/TestAutomatonAi.ps1`、`Tools/TestArmedGolemPickup.ps1`，以及现有炸弹、纸箱和躲避回归测试。脚本采用 Unity 替身，不替代游戏内验证。
