# 极简几何树

预制体：`Assets/Prefabs/Decorations/GeometricTree.prefab`，拖入场景即可使用，不替换原有 PixelTree。

沿用极简煤油路灯的平面几何风格，树干宽从 0.22 增至 0.34（约加粗 55%）。树冠改为左右对称、宽高接近的八边形，顶端亮面收进轮廓，并增加左右对称的两块低对比叶簇切面。总计五块几何，仍无像素纹理、叶脉、树皮、描边、粒子或灯光。默认宽 1.9、高约 3.22 世界单位，原点在树干底部。

Inspector 可修改树干宽高、树冠大小/中心、树干/树冠/顶面/叶簇切面颜色；根节点缩放控制整体大小。编辑器可直接预览。所有几何合并为一个 MeshRenderer，只有参数变更时才重建。

与路灯一致，只有树干底部有实体碰撞，默认范围宽 0.34、高 0.26、中心 `(0, 0.13)`，可用 `Solid Base` 关闭，`Base Collision Height` 调整深度；不应直接改碰撞器尺寸，组件重建会按参数同步。上方树干、树冠不挡路，但以排序 5 遮挡排序 1 的角色。无需加入 Blocks 层，不额外阻挡视野或修改主摄像机。

当前未自动放入任何场景。可配合沙漠城市滤镜；若需要更枯黄的外观，直接调节两种树冠颜色即可。
