# 电池与电池槽

## 预制体

- `Assets/Resources/PickupItems/BatteryPickupItem.prefab`：魔力电池，红色外壳、灰色金属端盖、浅灰色正极符号。内部物品 ID 仍为 `battery`，沿用拾取、背包图标、Q 放下及掉落物读档的公共流程。
- `Assets/Prefabs/Decorations/BatterySocket.prefab`：红灰电池槽，单张程序化精灵，提供可见的空槽／已安装两种状态。使用 Default 层与实体碰撞，受视野遮罩覆盖但不阻挡视线；具备距离加载豁免，隐藏槽不会绕过供电条件。
- 电池、电池槽和控制器的旧 Visible Non Blocking 场景覆盖在视觉初始化时迁回 Default，拾取电池的呼吸动画子对象同步到本体层。电缆始终使用 Default 层和默认排序层，排序上限为 0，低于角色和幽灵的 1；不会被遮罩后补绘的相机再次画到角色上方。仅改变渲染归属，不改碰撞箱、供电、交互提示与自动避障。

## 编辑器配置

1. 将电池槽拖入场景。
2. 在 `Battery Socket > Linked Mechanism` 中拖入一个场景内的 `WaterwayGateController`（水闸控制器）或 `LeverData`（普通拉杆）组件。不支持的组件会被拒绝。
3. 勾选 **默认带有电池**，首次进入场景时即有一块可以卸下并放入背包的电池；默认不勾选。编辑器中的槽体外观会同步更新。
4. `Interaction Distance` 调整交互距离，默认为 1.25。

本次仅创建预制体，没有擅自给已有场景机关增加供电需求。未绑定的控制器和拉杆保持原来的功能。

## 操作

- 地面电池：E 拾取，Q 放下，每格最多一块；R 无效，不会使用、消耗或触发装箱快捷行为。
- 空电池槽：靠近并朝向槽按 E，从当前选中电池开始安装；若当前格不是电池，自动寻找背包内的电池。不直接消耗地面上的电池。
- 已安装：按 E 卸回背包；满包时显示提示并保持电池和供电不变，不会掉落或销毁。
- 缺少电池：提示“背包中没有魔力电池”。死亡、幽灵、暂停或菜单阻断时不能安装或卸下。
- 拔出电池仅阻止后续控制器／拉杆操作，不改变正在运动或已完成动作的机关状态，也不会取代水闸淡入淡出的忙碌锁。
- 玩家操作、机关人偶触发拉杆、控制器的 SetOpen/ToggleFromExternal 接口均检查供电。直接操纵水闸的剧情／读档接口仍可用。
- 一个槽绑定一个机关；如果手动将多个槽绑定同一机关，则要求这些槽全部有电池。

## 整数电量与事件扣电

- `BatteryPickupItem` 提供 `电量上限` 与 `剩余电量`，均为整数，默认 **5/5**。独立电池的 `RemainingCharge` / `MaximumCharge`、电池槽的同名属性可供脚本查询。0 电量仍是已安装电池，可卸下、拾取和放下，但不再为绑定机关供电；受伤爆炸规则不变。
- 将需要消耗电量的机关 UnityEvent 绑定到电池槽的 **BatterySocket → ConsumeChargeFrom(MonoBehaviour)**，参数拖入该槽 `Linked Mechanism` 所绑定的组件。每收到一次来自该绑定对象的调用扣 **1** 点，不会变成负数，其他对象调用无效。脚本也可使用返回是否成功的 `TryConsumeCharge()`。当前不自动订阅拉杆、水闸控制器或水闸的任何事件，现有水闸开关不会扣电；后续只绑定实际需要计费的事件，避免同一次操作绑定多个阶段重复扣电。
- 地面电池、槽内电池、物品栏和说明窗口图标的中心红色区域随电量从上往下缩减；外壳、金属端盖及正极符号保留，0 电量显示灰色内芯，区别于空槽。拾取图标只缓存最多 8 个小型精灵，不为每个物品栏实例重建材质或修改共享 prefab。
- 通过版本化整数状态 `battery-charge-v1:上限:剩余` 保存，并将剩余值同步到现有 `hasStoredCharge/storedCharge` 以兼容物品系统。已有的背包、纸箱、放下、场景快照与磁盘存档传递 `itemState`，因此安装／卸下、换场景与读档不会充满电；旧存档没有任何电量记录时按满电 5 点迁移，显式保存的 0 不会被重置。上限也随电池一起保存。
- `Tools/TestBatterySocket.ps1` 覆盖来源过滤、一次扣 1、0 电量断电、装卸和跨场景状态恢复；`Tools/TestBatteryExplosion.ps1` 覆盖 0～5 各档、背包／地面状态恢复、旧存档兼容、可配置上限和图标接线。通过 Unity 项目编译，尚未 Play Mode 验证。

## 受伤爆炸

- 地面魔力电池、已装入槽内的魔力电池受到任意正值攻击伤害时立即引爆一次；0 或负值不算伤害。所有共用 `ZeldaAttackHitbox` 的攻击和爆炸均可触发，支持电池／炸弹之间的连锁爆炸。
- 从普通 `BombPickupItem` 资源继承完整配置，只覆盖攻击力为 **4**。当前伤害框为 **2.4 × 2.4** 世界单位、吸引半径为 **7**，视觉、音效与吸引波使用普通炸弹实现，后续修改普通炸弹配置会同步生效。
- 地面电池引爆时立即停用、禁止拾取并销毁；装载中的电池先清空槽内物品及存档身份、切断供电，再爆炸。电池槽与电缆保留，可重新安装电池；空槽不会引爆。不会因为持有者受伤而引爆背包内物品。
- `Tools/TestBatteryExplosion.ps1` 验证真实电池方法、攻击力覆盖、场景和攻击者归属、重复触发及缺失资源保护；`Tools/TestBatterySocket.ps1` 覆盖槽内引爆、清空存档状态、断电与重新安装。另通过炸弹音效、攻击及控制器回归测试；未在 Unity Play Mode 验收。

## 红灰直角电缆

电池槽预制体已附带 `BatterySocketCable`，可连接拉杆、水闸控制器、有面板的电门柱和警报器。未绑定或解除绑定时隐藏。空电池槽仍显示电缆，不改变供电规则。

- 电池有剩余电量时芯线为红色；未安装或耗尽时为浅灰色。灰色外套和深灰细边不变，仅在电力状态变化时更新颜色，不重排路线。一个合并网格，无碰撞和视线阻挡。
- **不再扫描或绕开 Blocks、碰撞体、其他设备。** 新路线允许穿过墙体，墙体变化不重建路线，也不会因墙把端口封住而隐藏整条电缆。
- 保持水平/竖直直角走线、随设备变换的局部底座接口（电门柱接面板），以及默认 0.28 的底部直线接线段。只为自身两端外壳整理接线方向；端点外壳重叠时仍用直角路径连接，不因避障失败消失。
- 新电缆参考先前已生成电缆的占用带，尽量减少长段重合；**已经生成的电缆不因其他电缆变化而重新避让**。保留稳定的自然错位，默认 0.45、每次至多增加两个装饰性直角；电缆间距默认 0.18。
- 线路与输送光效使用 Default 层，排序上限改为 -1，低于普通墙体（0）、角色及幽灵（1）；游戏内既有 Blocks Overlay Camera 在世界/遮罩之后绘制 Blocks，因此包括负排序柱体在内的 Blocks 都会盖住电缆，不改变墙体材质、判定或视野规则。

### 尽量保留已有路线

优先沿用内存中的折点或隐藏序列化缓存。首次升级时，如果旧版本已生成的电缆网格还存在，会从其三层条带恢复中心路径，沿用原折点，不按新规则重新布局。脚本重载时会接管旧网格，避免产生重叠副本。

缓存随场景保存，不因重新启用、距离加载、墙体变化、其他线路更新或颜色/宽度修改而重排。**请正常保存已打开的场景以保留恢复后的路径。** 新建连接、绑定对象或端点位置/朝向/缩放改变时按新规则生成；组件菜单“重新生成电缆”可明确放弃旧路径重建。若只修改自然错位等布局参数，也使用此菜单应用新布局。

旧版本从未保存过路径，因此尚未加载、且没有现存网格或路径缓存的线路不能精确还原，会在首次加载时用新规则生成；不会声称这些线路绝对不变。未批量重写正式关卡文件。

原有 `wallClearance` / `detourMargin` 序列化字段保留，Inspector 改称“端口留白” / “接线搜索余量”，仅用于接头与电缆间的路径整理，不再避开场景障碍。

`Tools/TestBatterySocketCable.ps1` 保留底层通用寻路器、端口变换、稳定错位及分线回归，并检查组件不再收集场景障碍。颜色检查 95 项，流动光效检查 104,290 项。
`Tools/BatteryCableRoutingSmoke.cs` 用隔离 Unity 工程测试生产电缆组件：有墙/无墙生成结果一致、旧网格恢复、禁用再启用、宽度改变不重排、实际场景保存再打开、移动端点及手动重建，以及电缆与加法光效被普通墙和 Blocks 覆盖相机遮挡。测试设备使用简化替身，不修改用户场景。

## 电缆输送光效

`BatterySocketCable` 在运行时为有电的线路显示暖红色流动光带，浅亮色前端配红色短尾迹和柔和外沿，从电池槽底座沿现有直角路径向绑定设备移动。
仅当自身电池槽 `HasPower`（已安装电池且剩余电量大于 0）且线路有效时启用，不要求机关当前处于打开状态。没有绑定、寻路失败、卸下电池、耗尽或爆炸清空时停止并清除显示；重新供电、重新生成路线或重新启用后从电池端重新开始，不在设备端凭空生成光带。

在组件的“电流输送光效”分组可调整：

- 显示输送光效：默认开启；编辑器非运行状态不播放。
- 光带移动速度：默认每秒 2.4 世界单位，沿路径实际长度匀速移动。
- 光带发射间隔：默认 2 秒；较长线路可同时看到多道间隔光带。
- 光带长度：默认 0.75 世界单位；自动限制为光带间距的 60% 以内，以保留明显间歇。
- 光带亮度：默认 1.2，设为 0 隐藏。

使用一个额外的合并条带网格和专用加法混合着色器 `Resources/BatteryCableFlow.shader`。顶点 UV 记录从电池端起的世界弧长，转角共用顶点，不走斜线、不在拐角叠加两次亮度；极短折段局部收窄以避免三角形翻转。端口、父级旋转、负缩放和路径变更时随原电缆重建，平时仅上传一个行进距离参数，不逐帧重新寻路、重建几何或生成粒子对象。

使用 `Time.deltaTime`，随游戏暂停冻结；动画相位不存入存档，电量仍以原有存档数据为准。运行很久后仅按整数个光带间距折返相位，不出现倒流或首道光带之前亮起。
光效始终使用 Default 层、排序上限 -1，低于普通墙体（0）、角色与幽灵（1）及视野遮罩（30000）；不修改全局 CRT／泛光、碰撞或现有供电扣电逻辑。

验证：`Tools/TestBatteryCableFlow.ps1` 覆盖实际几何方法、长时间相位、断电恢复、暂停及生命周期；原有电缆变色、寻路与电池槽检查均通过，Unity API 项目编译零错误、零警告。
`Tools/BatteryCableFlowSmoke.cs` 在隔离 Unity 2021.3 GPU 工程中验证实际着色器，已通过光带前进方向、直角转弯、间歇多光带、暖红色输出和关闭后零残留测试。该测试需配合从生产脚本提取的 `FlowGeometry.BuildFlowStrip`，不挂载到正式项目。
尚未在实际关卡的 CRT 滤镜下进行人工观感验收。

## 保存与资源说明

电池实例 ID、名称、说明及已有物品数据在安装、卸下间保留。电池槽加入现有 SceneTravelStateManager 场景快照及磁盘存档；读档状态优先于“默认带有电池”，不会因卸载重进或读档重新补发电池。默认电池的实例 ID 只生成一次。旧场景快照没有电池槽字段时保留初始配置。

安装中的电池由槽保存，不另建隐藏的电池对象；背包和地面使用原有拾取物流程。没有新增贴图资源、下载资源、全屏效果或持续扫描所有场景对象。
