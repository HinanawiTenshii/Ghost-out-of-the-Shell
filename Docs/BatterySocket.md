# 电池与电池槽

## 预制体

- `Assets/Resources/PickupItems/BatteryPickupItem.prefab`：电池，红色外壳、灰色金属端盖、浅灰色正极符号。放在 Resources/PickupItems 中，沿用拾取、背包图标、Q 放下及掉落物读档的公共流程。
- `Assets/Prefabs/Decorations/BatterySocket.prefab`：红灰电池槽，单张程序化精灵，提供可见的空槽／已安装两种状态。使用 Default 层与实体碰撞，受视野遮罩覆盖但不阻挡视线；具备距离加载豁免，隐藏槽不会绕过供电条件。
- 电池、电池槽和控制器的旧 Visible Non Blocking 场景覆盖在视觉初始化时迁回 Default，拾取电池的呼吸动画子对象同步到本体层。电缆始终使用 Default 层和默认排序层，排序上限为 0，低于角色和幽灵的 1；不会被遮罩后补绘的相机再次画到角色上方。仅改变渲染归属，不改碰撞箱、供电、交互提示与自动避障。

## 编辑器配置

1. 将电池槽拖入场景。
2. 在 `Battery Socket > Linked Mechanism` 中拖入一个场景内的 `WaterwayGateController`（水闸控制器）或 `LeverData`（普通拉杆）组件。不支持的组件会被拒绝。
3. 勾选 **默认带有电池**，首次进入场景时即有一块可以卸下并放入背包的电池；默认不勾选。编辑器中的槽体外观会同步更新。
4. `Interaction Distance` 调整交互距离，默认为 1.25。

本次仅创建预制体，没有擅自给已有场景机关增加供电需求。未绑定的控制器和拉杆保持原来的功能。

## 操作

- 地面电池：E 拾取，Q 放下，每格最多一块；R 无效，不会使用、消耗或触发装箱快捷行为。
- 空电池槽：靠近并朝向槽按 E，从当前选中电池开始安装；若当前格不是电池，自动寻找背包内的电池。不直接消耗地面上的电池。
- 已安装：按 E 卸回背包；满包时显示提示并保持电池和供电不变，不会掉落或销毁。
- 缺少电池：提示“背包中没有电池”。死亡、幽灵、暂停或菜单阻断时不能安装或卸下。
- 拔出电池仅阻止后续控制器／拉杆操作，不改变正在运动或已完成动作的机关状态，也不会取代水闸淡入淡出的忙碌锁。
- 玩家操作、机关人偶触发拉杆、控制器的 SetOpen/ToggleFromExternal 接口均检查供电。直接操纵水闸的剧情／读档接口仍可用。
- 一个槽绑定一个机关；如果手动将多个槽绑定同一机关，则要求这些槽全部有电池。

## 红灰直角电缆

电池槽预制体已附带 `BatterySocketCable`。绑定场景里的拉杆或水闸控制器后，编辑器和运行时会自动显示电缆；没有绑定或解除绑定时隐藏。电缆只标识绑定关系，空电池槽也显示，供电规则没有改变。

- 红色芯线、灰色外套、深灰细边，使用一个合并网格，不创建沿线的小物体，没有碰撞和视野阻挡。
- 接口固定在物体**自身局部坐标的底座中央**，不是屏幕朝下的一边：随位置、旋转、父级变换、缩放和负缩放翻转移动。倒转 180° 的控制器，接口会位于画面上侧的底座。控制器按固定外壳取点，拉杆按底座像素和原有非居中轴点计算，不受手柄摆动影响。
- 接口外保留一段朝底座外侧延伸的直线，默认最短 0.28 世界单位，可用“底部接线段长度”调整；中间线路将两个物体外壳也视作禁入区，不会重新穿过外壳接到别的边。两端接线段同样检查 Blocks 墙体，受阻时隐藏并提示，不会改用侧边／顶部接口。
- 主体布线仍按世界水平／竖直及方形 90° 拐角连接。90° 倍数旋转时出线方向准确随底座转动；任意角旋转时接口位置仍精确跟随底座中心，短出线段选择最接近的水平或竖直外侧方向，以保证没有斜线。
- 墙体避让采用同场景 Blocks 层启用的非触发 2D 碰撞体；忽略本线路电池槽、绑定机关及各自子物体的碰撞，避免端口被自身挡住。距离加载暂停的墙体仍参与避障，真正停用或禁用碰撞的墙体会被排除。
- 除 Blocks 墙体外，同场景的其他电池槽、水闸控制器和普通拉杆也作为硬障碍，按实际外形包围盒避让，不依赖其层级、碰撞箱或是否已绑定／生成电缆。可见物体即使行为脚本停用仍需避让；距离加载暂时停用的设备同样保留避让，真正隐藏的设备不占路径。
- `额外设备间距` 默认 0.12 世界单位，在线宽和离墙间距之外增加设备旁的留白。设备外形不包含提示文字和它自己的电缆，因此不会出现避让范围越算越大的问题。中间线路、自然转折和底座接线段均不能穿过其他设备；供电关系及底座接口不变。
- 使用障碍包围盒扩大电缆半宽及间距后寻路，确保线宽不擦入墙内；不规则障碍使用保守包围盒，可能比实际轮廓绕得略远。
- 四方向 A*，合并共线段并对拐角增加代价。优先检查简单直线／L 形路径，必要时逐级扩大绕行范围；不会在失败时退回穿墙直线。
- 自然走线默认每条最多增加两个直角：足够长的直线做小幅侧向错位，宽敞的 L 形改为不等长的阶梯转折。短连接和狭窄位置不会强行加拐角；新增转折不能穿墙、自相交或增加与其他电缆的重合。
- 同场景电缆按层级顺序稳定避让，后面的线路优先绕开前面线路的占用带；长段重合代价高于短暂垂直交叉。共享端口、极窄通道允许必要的短交叉或共线，不会只因无法完全分线而断开连接。线路变化只向后传播，不会互相追逐重算。
- `自然错位幅度` 默认 0.45，设为 0 取消装饰性拐角；`电缆间距` 默认 0.18，是线宽之外的额外避让间距。错位采用稳定的层级种子，不使用每帧随机数，重复刷新不会抖动。
- 移动端点立即重建；背景障碍默认每 0.5 秒检查一次，新建碰撞体默认 2 秒内发现。几何不变时不重新寻路或生成网格。编辑器可用组件菜单“重新生成电缆”强制刷新。
- Inspector 可调整电缆宽度、离墙间距、最大绕行范围（默认 32 世界单位）、寻路节点上限及底部接线段长度。旧的自由端口偏移已移除，避免把接口移出底座。接口在其他墙体内部、区域封闭或超出预算时隐藏线路并输出一次警告；可移动物体，或调整绕行范围及节点上限。

`Tools/TestBatterySocketCable.ps1` 对实际寻路、端口计算及设备收集源码执行三万余项检查，包含窄缝、薄墙、封闭区域、多拐角、随机障碍、安全间距、自然转折上限、共享端口分线、狭窄处降级、重复生成稳定性，以及不同方向的底座出线、180° 倒转、任意旋转、非均匀缩放及负缩放。额外覆盖非 Blocks 层设备、无电缆设备、行为脚本停用、主动隐藏与距离卸载区别、移动后更新、设备堵住端口时安全失败，以及线路拥挤降级时仍不得穿过设备。`Docs/BatterySocketCable-preview.png` 为三条线路连接正常电池槽与倒转控制器的算法示意，不是 Unity 实机截图。电池和控制器回归检查通过；尚未 Play Mode 验收场景内最终效果。

## 保存与资源说明

电池实例 ID、名称、说明及已有物品数据在安装、卸下间保留。电池槽加入现有 SceneTravelStateManager 场景快照及磁盘存档；读档状态优先于“默认带有电池”，不会因卸载重进或读档重新补发电池。默认电池的实例 ID 只生成一次。旧场景快照没有电池槽字段时保留初始配置。

安装中的电池由槽保存，不另建隐藏的电池对象；背包和地面使用原有拾取物流程。没有新增贴图资源、下载资源、全屏效果或持续扫描所有场景对象。
