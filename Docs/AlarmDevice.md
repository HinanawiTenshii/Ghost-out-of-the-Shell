# 警报器

预制体：`Assets/Prefabs/Decorations/AlarmDevice.prefab`。

## 配置

1. 将警报器放入关卡，在 `AlarmDevice / Responders` 中拖入同场景的角色（最多 10 个）。空项忽略，重复项只派遣一次。
2. 在一个 `BatterySocket / Linked Mechanism` 中拖入该警报器。电缆从本地底部连接，沿用当前不绕场景障碍、优先保留已有路线的规则。
3. 安装有剩余电量的魔力电池，或勾选电池槽默认带电池。未绑定、空槽、电量为零时均不可使用；有电时靠近按 E。当前不额外消耗电量。

## 行为

- 魔幻中世纪要塞风格：开放式灰铁支架、红色分面铃体、顶部红色绑带、外露木柄铁锤和菱形魔力石。移除封闭电器外壳、现代按键和通风格栅，保持严格俯视角与粗几何体造型。
- 魔力石无电时暗灰，有电时亮红，触发后短暂闪动。保持单网格；占地仍为 0.9 × 1.1，碰撞箱、底部接线位置及全部交互/AI 功能不变。
- 使用现有交互优先级及伸手动画，幽灵无法操作。默认范围 1.4，重复触发间隔 1.2 秒。
- 唤醒由摄像机距离加载暂停的绑定角色，立即进入前往事发点、附近搜索、返回出生位置的流程。搜索范围、时长、路径及视线判定沿用各角色现有 AI 配置。
- 搜索中发现玩家则转入敌对，失去目标后沿用既有搜索/返回流程。搜索、战斗、返回阶段保持加载；返回并 Idle 后由距离加载系统管理，**不会被警报器强制停用**。
- 昏迷角色保留昏迷，醒来后执行派遣；重复启动会更新搜索地点。不会复活死亡角色，也不会接管玩家当前控制或正在附身的角色。
- 非距离加载造成的禁用（关闭 AI、手动关闭物体或父层级）不被强制打开。此预制体针对地图中的正常 NPC。
- 自动人偶若被明确绑定，会临时执行警报搜索/返回；未派遣时保持原有待机/敌对规则，不改变其激活开关。
- 保存派遣及事发点状态；读档延续搜索，跨场景返回沿用既有返回原位策略。无需警报器持续存在，角色也能自行完成返回。

外部脚本可调用 `ActivateAlarm()`（UnityEvent）或 `TryActivate()`（返回是否触发）；两者同样检查电源与冷却。

视觉使用 Default 层，受现有视野遮罩管理；预制体具备碰撞但不作为 Blocks 视线障碍。
