# 纸箱中的炸弹

- 选中普通炸弹或超级炸弹，靠近空纸箱按 **R**：放入并点燃，使用该炸弹预制体的引线时长，到时炸毁纸箱并爆炸。
- 同样条件下按 **Q**：安全存放，不运行引线；纸箱被摧毁时仍会引爆炸弹。按 E 收起纸箱会释放可拾取的炸弹，沿用此前的回收方式。
- 已点燃的炸弹不会因收起纸箱而熄灭：收起后在原位置留下继续倒计时的炸弹，不重置剩余引线。
- 没有可用空纸箱时，R 保持正常放置引燃炸弹，Q 保持丢出未点燃物品；其他物品行为不变。
- 引燃纸箱及炸弹爆炸/吸引范围内对象保持加载；保存时记录剩余引线、引燃标志及使用者身份。旧存档的安全存放状态保持不变。

验证：`pwsh -NoProfile -File Tools/TestBoxBombModes.ps1`。该测试运行提取的生产倒计时与释放分支，并检查 R/Q、事务回滚和存档接入；仍需在 Unity 中实测爆炸、拾取与存档恢复。
