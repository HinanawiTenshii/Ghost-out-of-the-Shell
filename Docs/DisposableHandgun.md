# 一次性手铳

预制体：`Assets/Resources/PickupItems/DisposableHandgunPickupItem.prefab`

- 名称：一次性手铳；物品 ID：`disposable_handgun`；每格最多 3 件。拾取按同类物品堆叠，旧存档带独立 ID 的手铳可在后续拾取时加入堆叠；成功发射或放下仍只消耗 1 件。
- 说明：装填了一发子弹的一次性手铳，在发射一发子弹后就会被废弃。
- 使用现有 E 拾取、Q 放下、R 使用、物品信息与存档机制。Resources 物品缓存及存档模板缓存自动收录，不需要修改场景或目录表。
- R 发射一发子弹并消耗物品；靠近纸箱时不会把 R 操作转为收纳。无有效受控角色、幽灵或死亡角色无法发射，也不消耗物品。
- 子弹沿发射瞬间的角色朝向直线飞行，默认速度 10 世界单位/秒，可在物品 Inspector 的 `Bullet Speed` 中修改。生命期固定为 5 秒游戏时间；暂停时不会继续运动或计时。
- 使用连续圆形扫掠检测，按最近有效接触点处理，避免高速穿过薄墙。发射者自身碰撞箱排除；命中角色、障碍或现有可受击道具后立即结束，最多处理一次命中。
- 攻击力固定 2，保留现有偷袭倍率、免疫、受伤音效和骨牌传导。角色命中改为匿名伤害：不触发玩家攻击的直接报复或目击敌意，存活者前往发射位置调查。免疫角色仍拦截子弹，但不强制突破其伤害免疫。详见 `Docs/HandgunAudioAndInvestigation.md`。
- 支持门/玻璃、纸箱、地面和槽内电池、炸弹、已放置炸弹、稳定结晶及训练人偶的既有受击响应。普通交互区域触发器与不可受击的拾取物不拦截；Blocks / Hidden Blocks 层和其他实体碰撞体拦截。
- 子弹归属发射时的实际关卡，不跟随角色切换或死亡销毁；离开关卡时随场景清理。短距离动态保留区域唤醒前方被视野加载系统暂停的目标；不打开远处视野，也不永久保留目标。
- 手铳为粗像素灰钢枪管、金铜配件、褐色木柄，子弹为短暖色亮点，沿用世界视野遮罩。发射时播放短促黑火药爆响（0.32 秒）；未改动已有场景。

## 出手与四向发射

- 使用 `ZeldaFourWayMover.TryBeginItemAttack` 进入现有角色攻击姿态，沿用出手与攻击期间的移动锁定，但不创建角色原来的近战武器、伤害框或近战音效。攻击期间再次使用不会消耗另一件手铳。
- 手持手铳使用上下两张独立的纵向视图，以及保持握柄朝下的左右镜像视图。灰钢枪管、金铜配件、褐色木柄与场景拾取物一致；拾取物仍保持 `worldScale: 0.5`，背包图标未改变。
- 武器握柄对齐现有出手帧的手部中心，使用角色贴图实际 pivot、PPU、缩放和翻转计算位置。强壮角色、重装圣骑士、厨师、巨兽等采用对应的手部坐标。工匠使用保留出手但不绘制锤子的临时帧；普通攻击及待机锤子不变。
- 抬手时从手铳枪管端点生成一发子弹，伴随 0.045 秒枪口亮点和约 0.12 秒短促后坐；总动作约 0.28～0.45 秒。枪口与子弹共用同一套像素坐标，不用固定的角色中心偏移。
- 从角色到枪口额外执行一次连续碰撞检查。枪口越过薄墙、玻璃或目标时，子弹在第一个接触处结算并消失，不穿墙生成。
- 动作结束、死亡、失去控制、进入幽灵状态或眩晕取消攻击时清理手持武器及临时姿态；已发射子弹保持独立生命周期。
- `Docs/HandgunFiring-preview.png` 是代码像素图的四向预览，不是 Unity 实机截图。

## 验证

- `Tools/TestHandgunStacking.ps1`：18 项拾取、每格 3 件、满包保留、单件消耗和旧独立物品堆叠兼容检查；保留电池和结晶的既有规则。
- `Tools/TestDisposableHandgun.ps1`：64 项生产方法断言，以及预制体描述、物品 ID、脚本引用、16×16 图标校验。覆盖无效使用不消耗、重复使用防护、四向运动、5 秒寿命、薄墙/最近目标、多个碰撞箱、回调重入、免疫、跨场景归属、发射者死亡、各类道具命中、枪口出生点防穿墙、发射位置快照和单次音效。
- `Tools/TestHandgunFiring.ps1`：541 项生产发射/姿态/枪口/四向贴图断言；可传入 `-RenderPreview` 重新生成预览。额外以现有工匠像素测试替身验证四个无锤出手帧均移除了锤子，且身体保持连通。
- 物理查询使用简化扫掠 AABB 替身，不等于 Unity 实机验证。
- 使用 `Tools/DisposableHandgun.Validation.targets` 编译 C# 项目：0 警告、0 错误。
- 尚未 Unity Play Mode 验收。建议将预制体拖入测试场景，检查 E/Q/R、四个朝向贴墙射击、角色与电池受击，以及拾取后保存/读档再发射。
