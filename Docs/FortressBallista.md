# 可操作弩炮

预制体：`Assets/Prefabs/Decorations/Fortress/Fortress-Ballista.prefab`。

- 站在尾部附近并面向尾部把手，出现「按[E]发射弩炮」。幽灵、死亡角色以及打开菜单/暂停时不能操作；交互经过现有 E 键目标仲裁，不同时触发附近其他对象。
- 弩炮自身局部 +Y 为箭头方向，局部 -Y 为尾部。参考截图旋转 90° 后向左射击，操作区在右侧；旋转、非均匀缩放、镜像和视觉组件 Size 都会同步影响操作区、把手位置和发射方向。选中对象可看到青色操作范围线框。
- 按 E 发射一次并冷却 3 秒，冷却期间不显示可用提示；不消耗背包物品。角色伸手，弩炮外观发生约 0.3 秒的后坐/左右抖动，根 Transform 和碰撞箱不移动。停用时恢复原位。
- 箭矢默认速度 12 世界单位/秒，从箭头端发射；角色进入箭矢当前的爆炸区域时近炸引爆，不需要箭矢直接碰到该角色。直接碰撞和飞行 4 秒后的超时引爆也仍然保留。
- 近炸区域与实际伤害判定一致，为世界坐标轴对齐的 1.6 × 1.6 正方形。只检测同场景、未死亡且可受攻击伤害的角色（含发射者）；幽灵、尸体和非角色物体不触发近炸。墙、玻璃、电池、纸箱等仍需箭矢直接碰撞才引爆；纯权限区等非实体触发器不拦截。
- 使用 OverlapBox 检测当前区域、BoxCast 连续扫掠近炸区域，避免高速飞行漏检。保留 CircleCast 的实体碰撞检测，与近炸结果比较，采用路径上先发生的事件；发射弩炮自身不作为碰撞目标，每支箭仅爆炸一次。先唤醒距离卸载的角色，再检测近炸。
- 爆炸 attackPower 固定为 8，判定尺寸 1.6 × 1.6（普通炸弹为 2.4 × 2.4），灰白爆心与白色碎屑。复用 `ZeldaAttackHitbox`，包含角色、门/玻璃及现有可破坏物品的伤害和连锁处理；同一角色多个碰撞箱只受伤一次，范围内也可伤及操作者。
- 发射后切换控制或操作者死亡不会取消箭矢；伤害归属仍是发射时的角色。箭矢周边短距离与爆炸范围使用现有保活区域，先唤醒距离卸载的目标再查询碰撞。视觉仍在普通世界层，受视野遮罩影响。

`FortressBallista` Inspector 可调整 Rear Reach（默认 1.25）、Rear Half Width（0.8）、Facing Threshold（0.6）和 Bolt Speed（12）。冷却与攻击力按当前需求固定为 3 秒/8。

新增脚本：`Interaction/FortressBallista.cs`、`Items/FortressBallistaBolt.cs`。无需给实例单独增加子对象或手工调整触发器；保留现有整个弩炮的 BoxCollider2D。已有已连接该 prefab 的实例会继承组件。未更改关卡场景文件。

## 机关人偶操作

- 遥控机关人偶靠近弩炮尾部，按 **E** 附着。只接受尾部附近的操作，不允许从前方、侧面、远处或隔着实体障碍直接吸附；每台弩炮同时只能附着一个人偶。
- 附着后按 **E** 发射；冷却中显示「弩炮冷却中」。使用同一箭矢、3 秒冷却和抖动逻辑，成功发射才扣除一次人偶的 `Operation Magic Cost`（当前人偶预制体为 5）；冷却中重复按键不扣能量。
- 按 **R** 退出控制不会让人偶自动发射，也不会解除附着；之后用对应魔力遥控器重新接管即可继续发射。回收、能量耗尽遵循人偶已有规则。
- 纸箱中的人偶也可在尾部按 E 出箱并附着，保留其唯一身份、能量和遥控器绑定。
- 附着点随弩炮的旋转、缩放、镜像同步变化；只忽略人偶与该弩炮的碰撞，保留弩炮对其他角色的实体碰撞。弩炮被停用或销毁时解除附着。
- 场景快照和磁盘存档记录弩炮的稳定路径；返回场景或读档时恢复附着。旧存档没有这一字段时照旧恢复拉杆或未附着状态。

## 验证

`Tools/Ballista.Validation.targets` 编译完整项目并包含新增脚本；`Tools/TestBallista.ps1` 检查 prefab 引用、固定数值和集成调用。

`Tools/BallistaSmoke.cs` 是隔离 Unity 2021.3 工程的 Play Mode 入口。搭配 `Tools/BallistaSmokeStubs.cs`，复制生产弩炮、箭矢、几何、伤害判定、爆炸视觉与保活区域脚本后执行 `BallistaSmoke.Run`。使用真实 Unity 2D 物理和生产 `ZeldaAttackHitbox`；角色数据、输入仲裁和加载管理器为测试替身，不等同于在用户关卡中手工操作验证。覆盖旋转/缩放、尾部/朝向、冷却、暂停、幽灵、薄墙、最近命中、炮口阻塞、超时、灰白范围、玻璃、复合角色碰撞、伤害归属和保活唤醒。

`Tools/ClockworkBallistaSmoke.cs` 由 `ClockworkRemoteSmoke.Run` 在隔离工程内调用，使用完整生产脚本与实际预制体验证附着区域／遮挡、碰撞过滤、旋转缩放、能量消耗、冷却、重新接管、场景附着恢复、耗尽清理、出箱附着及原角色操作回归。
