# Hidden Blocks 层

已添加 Unity Layer 8：`Hidden Blocks`。原 `Blocks` 保持 Layer 7，不改变现有对象的层级。

## 使用

将需要“遮挡玩家视野，但自身也受视野遮罩隐藏”的物体设为 `Hidden Blocks`，并保留有效的 `Collider2D`（普通墙体建议非 Trigger）。若渲染器和碰撞体位于子对象，需要将对应子对象也设为此层，不能只修改空父对象的 Layer。

物体仍使用普通场景渲染顺序，不应放到 UI 层或使用越过视野遮罩的渲染材质/排序。当前主摄像机已包含该层；自定义摄像机也需要在 Culling Mask 中包含它。

## 行为

- `Blocks`：阻挡视野，通过额外摄像机在遮罩上方重绘，因此盲区内仍能显示。
- `Hidden Blocks`：同样阻挡玩家和机关人偶揭示区域的视野，但不参与遮罩上方的重绘；盲区内被遮罩覆盖。
- 两层均按遮挡物规则保留附近碰撞体，不会因暂时看不见而卸载碰撞体，导致视线穿透。
- 原 AI 侦测、地图绘制等独立 LayerMask 不自动改变，本次仅新增玩家视野层语义。未将现有物体批量改层。

`CameraCircularVision` 启动、场景刷新和编辑器校验时自动将新层加入遮挡查询，即使旧场景仍保存仅含 Blocks 的遮挡掩码也能兼容。两个渲染通道的掩码独立处理，避免将新层误当作始终可见的墙体。
