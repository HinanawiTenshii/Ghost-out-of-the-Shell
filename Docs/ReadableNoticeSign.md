# 可阅读告示牌

预制体：`Assets/Prefabs/Decorations/ReadableNoticeSign.prefab`。

拖入场景后，在 **Signpost Interaction → 告示文字** 中填写内容，支持换行；已启用“告示牌模式”，无需填写四方向文字。`Interaction Distance` 默认 1.5，`Display Font` 已绑定项目中文像素字体。

- 造型：1.4 宽、0.82 高的矩形木牌；总高 1.08，底部露出的短杆约 0.26。木褐色外框和两条简洁刻痕，与已有指路牌保持几何风格。五个矩形合并到一个网格，共十个三角形。
- 编辑器中实时生成外观，底部碰撞体宽 0.16、高 0.22；默认层保持现有指路牌规则，不额外添加视野阻挡层。
- 靠近提示“按[E]阅读告示牌”。阅读时显示居中的 420×220 深蓝文字卡片与青色细框，保留弹窗泛光，正文居中换行并在 12～24 字号间自适应。空文字显示“暂无告示内容”。适合简短的多行公告。
- E 或 Esc 关闭，恢复打开前时间缩放；关闭当帧不同时触发其他交互或暂停菜单。禁用/卸载告示牌也会关闭窗口并恢复游戏。
- 按键提示是同场景内独立的根对象，保持单位缩放与正向旋转，不继承告示牌或其父对象的缩放、旋转、镜像。仍定位在角色头顶，告示牌禁用时隐藏、销毁时一并清理。
- 告示牌与指路牌阅读时，共用一个全屏黑色半透明背景，位于文字卡片之后；默认压暗 60%，可在 Inspector 的“阅读背景压暗程度”中调整。随阅读窗口一起关闭/销毁，不修改场景物体、灯光或摄像机颜色。
- 复用指路牌的交互仲裁、模态输入、CRT、字体和窗口置顶逻辑；已有三箭头指路牌及 `NoticeBoard.prefab` 公告板装饰不变。没有自动修改任何关卡场景。

验证：44 项指路牌/告示牌交互检查、几何边界与短杆比例检查、63 项 UI 泛光回归，以及 C# 编译。`ReadableNoticeSign-preview.png` 是生产网格的静态几何预览，不是 Unity/CRT 实机截图。仍需在 Unity Play Mode 中确认实际场景缩放和阅读观感。
