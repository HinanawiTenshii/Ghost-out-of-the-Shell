# 诱饵炸弹

预制体：`Assets/Resources/PickupItems/Bombs/DecoyBombPickupItem.prefab`；物品 ID：`decoy_bomb`。

说明：
> 以魔力信标取代引信的炸弹，启动后会引诱看见它的人前来攻击，也会成为沙虫优先吞食的目标。按R放置并启动，按Q仅放下。注意，信标不会自行引爆，但受到攻击仍会发生与普通炸弹相同的爆炸。

## 使用与行为

- R 使用：按现有规则放在面朝方向的小段距离处，受阻时退回脚下；启动红色信标，不会计时爆炸。
- Q 丢弃：仍是可以拾取的物品，不启动信标。未启动的诱饵受到攻击时也会爆炸，与普通炸弹一致。
- NPC 必须实际看到已启动的诱饵（沿用角色视角、视距与 Blocks 遮挡规则），才会记住并前往攻击。沿用既有寻路与攻击未命中后靠近重试机制，不用接近距离代替实际攻击命中。
- 看见诱饵的行为优先于原有目标追踪；不会因放置诱饵直接给玩家添加敌意。爆炸伤害仍走原有伤害逻辑。休眠的武装魔像不会被擅自激活，已激活魔像可以被诱导。
- 诱饵被引爆、吞食或移除后释放目标，恢复角色原有 AI；追击期间保留距离加载。
- 沙虫在地下游走或接近出土点时，优先追踪当前场景中可作为目标点的已启动诱饵，不必等待四次游走。多个诱饵优先最近的一个，选定后保持目标；已腾空的攻击不会中途改道。
- 沙虫接近途中诱饵失效时会改选其他诱饵或玩家；没有目标则恢复游走。吞食继续使用现有中段爆炸、双倍伤害、坠落与眩晕逻辑。
- 装在纸箱中的信标不可见，不吸引 NPC / 沙虫，也不计时；纸箱受损引爆、吞食内容物和释放内容物沿用现有规则。

## 数据与兼容

基础数据复制当前普通炸弹：attackpower 5、伤害盒 2.4×2.4、调查半径 7、每格堆叠 5、放置大小 0.55。爆炸视觉、音效与连锁爆炸共用普通炸弹实现。

新增 `BombPickupItem.IsDecoy` 模式，经 `CreateConfiguredPlacedBomb` 传入 `PlacedBomb`；没有引入新的存档设备类型。物品栏、跨场景与读档通过稳定物品 ID 和现有 bomb 设备标量配置恢复。

普通炸弹、超级炸弹及紫色炸弹外壳已移入 `PickupItems/Bombs`，保留原 `.meta` GUID；场景引用及旧物品 ID 不变。Resources 的普通炸弹直接加载路径同步更新，递归物品目录照常发现新物品。

## 验证

`Tools/DecoyBombSmoke.cs` 在隔离 Unity 工程运行：计时不爆、普通炸弹回归、保存字段恢复、Blocks 遮挡、未启动不吸引、真实 NPC 走近并命中引爆、休眠魔像限制、沙虫改道/吞食/体内爆炸与诱饵消失恢复。`Tools/TestBoxBombModes.ps1` 覆盖纸箱中的定时和诱饵差异。
