# 骨牌：只传导伤害

- 普通攻击沿用原有伤害计算，将结算后的伤害传给同组其他存活角色一次。传导伤害不再次传播、不再次套用受击者的偷袭倍率。致命攻击也只传这次伤害，不追加死亡或额外伤害。
- 成员死亡仅移除该成员的标记及流式加载豁免；至少两名成员存活时保留其链接，不足两名时清理链接。
- 普通附身和灵魂标记转移导致原身体死亡时，捕获原身体当时的剩余生命值并传导一次；不是最大生命值，也不是切换后新身体的生命值。先设置死亡防重入标记，再传导并清理链接。
- 移除“附身到任何骨牌成员都会强制杀死目标及原身体”的旧分支，统一走正常附身流程。新身体若同属原身体的链接组，仍承受该次传导，只有生命归零才死亡，并由正常死亡流程在新身体处生成幽灵；若不在同组，不受此传导影响。
- 灵魂标记转移自带的爆炸仍独立使用原有伤害规则，未改变其范围或攻击力。
- 技能说明已同步；技能费用、等级、人数、范围、选取方式及跨场景清理规则不变。
