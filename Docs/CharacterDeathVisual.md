# 角色死亡爆散

保留原来的像素十字轮廓与角色 `deathExplosionTint`，改为局部亮闪和块状碎裂，不使用炸弹的双层圆形爆炸、烟雾或全屏震动。

- 播放时长为角色原时长参数的 1.35 倍：普通角色从 0.35 秒延长至约 0.47 秒，巨兽的 0.5 秒延长至约 0.68 秒。无需修改场景或预制体的序列化值，原尺度与颜色参数不变。
- 十字亮闪仍迅速扩张，普通角色维持全亮约 0.056 秒，随后平滑淡出至约 0.168 秒（原截止约 0.09 秒），提高中心轮廓的可读性；不改变约 0.47 秒的整体时长和碎片运动。
- 十字从最大特效尺度的 0.06 倍起步（此前为 0.24），用平滑加速再减速的曲线在约 0.126 秒内长至原有 0.7 倍终点，强调从小到大的过程。不再复用碎片的快速衰减曲线；透明度、终点尺寸和消失时间不变。
- 8 块矩形碎片快速向外飞出，随后连续减速、收短并淡出；方向、距离、宽度、偏转和消失时刻有少量随机差异。早期保留亮度，避免刚出现就变淡。
- 无连续尾迹、碰撞器或伤害判定，不改变死亡通知、附身、音效及灵魂引爆逻辑。
- 所有实例共享一张 16×16 点采样纹理；每次死亡最多 9 个可见 SpriteRenderer，每帧不创建对象。结束后整个特效对象销毁。
- 特效继承角色排序层，在实际关卡场景中创建并豁免距离卸载，不会跟随旧身体消失，也不会在切换关卡后残留。
- 尺寸取死亡角色自身 `Visual` 身体精灵的最大世界边长（含 PPU、预制体及父级缩放），再乘原 `deathExplosionScale` 倍率；一单位身体保持原效果大小。中心使用死者身体中心，不读取当前控制角色或摄像机。不读取纹理像素，兼容不可读的程序化精灵。无身体精灵时退回死者自身碰撞箱，再退回自身 Transform 缩放。

验证：`Tools/TestDeathExplosionVisual.ps1` 检查正式动画曲线及接入约束，另外编译 Unity 运行时与编辑器程序集并回归音效测试。这些不代替 Unity 中开启 CRT 后的最终视觉验收。
