# 统一 UI 泛光

`RuntimeUiGlowScope` 沿用 `TitleScreenGlow` 的三层荧光效果。菜单/弹窗通过 `CRTScreenEffect.RegisterCanvas(canvas, enableGlow: true)` 主动启用，无需给每个按钮或文字逐一挂脚本。普通注册和场景 Canvas 自动发现不再附加 UI 泛光。

- 保留主菜单、Tab/暂停菜单、存档页、路牌/密码锁/电门面板、文本/物品说明/角色属性/需求窗口中的文字、明亮细边框、小图标和地图任务标记泛光。
- 关卡常驻 HUD（生命、能量、技能、物品栏、小地图、任务与权限信息）不再附加泛光；普通场景提示和加载遮罩也不自动启用。全局 CRT 扫描线、色差及场景发光特效不变。
- 蓝色文字维持主菜单的荧光蓝；游戏内青色文字与边框使用相同层次的青色光晕，但光晕强度降低 25% 以保持清晰度，核心亮度和色系不变。白色、红色、灰色等内容保留原色与较轻的光晕，禁用状态仍可辨认。
- 不处理大面积面板背景、暗色填充、RawImage/地图主画面或 Mask/RectMask2D 遮罩本身。原有 UI 材质、字体图集、裁剪、透明度、布局与点击范围不变。
- 使用 uGUI 自身的 GraphicRegistry 在渲染前发现动态元素，不逐帧扫描整个场景或层级。同一元素只挂一次效果；新弹窗、延迟布局和重新启用的菜单均可自动生效。
- 普通 Canvas 注册会移除旧自动泛光 Scope：仅在存在旧 Scope 时一次性清理包含隐藏子节点的效果；不清理属于嵌套弹窗 Canvas 的效果。跨场景重新注册 HUD 不会再次添加光晕，弹窗开关不影响 HUD。
- 超长文字保留既有顶点预算保护。场景编辑状态不自动挂载组件，关闭 Canvas 时取消事件订阅。

验证：`Tools/TestRuntimeUiGlow.ps1` 63 项，覆盖显式弹窗接入、HUD 默认无泛光、旧 HUD/隐藏节点清理、嵌套窗口保留与青色光晕；`Tools/TestTitleScreenGlow.ps1` 693 项主菜单网格检查。电门面板 904 项及路牌 36 项回归通过；完整 C# 编译通过。这些检查不替代 Unity 中的实际画面与裁剪观感验证。
