# 骷髅角色

预制体：`Assets/Prefabs/Level2Npcs/Skeleton-level2.prefab`。直接拖入场景使用，未自动摆放到现有关卡。

造型沿用现有角色的 16 PPU、16×20 四向像素规格：灰白骨骼、深色眼窝，短腿、无脖子、无武器，使用骨拳攻击。编辑器可见蓝色轮廓。

- 主动攻击视野内的非骷髅角色，包括普通 NPC 和玩家控制角色；遵守正常遮挡和幽灵不可攻击规则。
- 不以同类为目标，同类之间的近战不会互相造成伤害。普通 NPC 会将活着的非玩家控制骷髅识别为威胁。
- 死亡后按头骨、躯干、双臂、双腿分解（侧面被遮挡的手臂不会额外出现），散开、停留、回收拼合。碎骨只有 SpriteRenderer，没有碰撞箱或刚体。
- 重组期间角色不可行动、受伤、附身或阻挡移动；拼合完毕后满血复活，可重复触发。
- 复活时优先攻击视野中的非骷髅敌人；没有可见敌人则进入返回状态，沿原有寻路回到首次生成的位置，到达后待机。返回途中发现敌人会立即转入战斗，重复死亡不会把死亡地点变成新的出生点。
- 保留死亡通知与死亡音效，取代普通死亡爆炸。玩家控制骷髅死亡时仍产生幽灵，复活后恢复 NPC AI，不会抢回玩家控制。
- 保存剩余重组进度；重组期间保持加载，暂停时停止计时。跨场景时留在死亡场景，回来后继续保存的进度。

可在 `SkeletonZeldaCharacterData` 中调整：散开时长 `scatterDuration`（0.45 秒）、停留时长 `revivalDelay`（4 秒）、拼合时长 `assembleDuration`（1.2 秒）、散开距离 `scatterDistance`（1.25 本地单位）。默认生命 5、攻击力 2，可按关卡平衡调整。

验证：`Tools/TestSkeleton.ps1`、`Tools/TestAutomatonAi.ps1`，并回归普通死亡音效、骨牌伤害及附身流程。编译使用 `Tools/Skeleton.Validation.targets`。脚本测试使用 Unity 替身；仍需编辑器内验证实际碰撞、附身、场景往返与视野遮罩表现。
