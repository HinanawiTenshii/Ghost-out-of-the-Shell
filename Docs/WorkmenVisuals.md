# 工匠与 Strongman 四向重绘

沿用当前像素角色风格：头部直接衔接肩部，不画脖子；腿与脚合计两行，侧面手臂覆盖躯干中部。攻击时先还原原手臂下方的身体，再绘制出击手，避免重复手臂。

- **工匠**：保留原有 16×16、16 PPU 和支点。短发胡须、蓝灰上衣、棕色围裙与工作手套；长裤、肤色、头发、锤子等全部使用原序列化颜色，没有改动预制体的配色值。围裙正面与背后的系带独立绘制。锤子随朝向置于持握手旁，攻击时随同一只手伸出；装饰不改变 Hammer 攻击判定。行走范围改为 x=5..6、9..10，y=3..4。
- **Strongman**：保留 20×20 画布与 16 PPU，保持比普通角色更宽厚的体型、橙色无袖服装与粗壮裸露手臂。头肩相连、躯干逐渐收窄，深褐色短腿为 x=6..8、11..13，y=4..5。支点 y=0.3 抵消脚底缩短一行，世界空间落地高度不变。

工匠的配色仍可通过 Blacksmith Appearance 字段调整；运行时 Inspector 改色会在下次绘制重建待机、攻击及行走缓存。

没有修改属性、碰撞箱、AI、技能、攻击范围或攻击时间。Strongman 与其关卡变体通过同一脚本应用。

验证脚本：Tools/TestWorkmenVisuals.ps1，提取并执行生产绘图方法和行走变换，检查两种角色共 32 个四向待机/攻击/行走姿态、像素连通性、短腿、居中手部、攻击旧手移除和锤子存在性。预览输出 Docs/Workmen-Idle-preview.png、Workmen-Attack-preview.png、Workmen-Walk0-preview.png、Workmen-Walk1-preview.png。

预览不包含运行时整体色调、CRT 和伤害闪烁，最终效果需在 Unity 内确认。
