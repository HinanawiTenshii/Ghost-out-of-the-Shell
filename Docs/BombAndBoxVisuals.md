# 炸弹与纸箱视觉

炸弹采用 16×16，纸箱采用 24×20；均使用 Point 采样的硬边色块，不使用平滑渐变或细碎纹理。

- 普通炸弹：深灰块面弹体、短高光、金属顶盖与弯折的短引线。
- 超级炸弹：保留紫色，外壳肩部更宽；深色横向加强带与方形扣件区分普通版本。原有紫色粒子保留。
- 纸箱：按原版 48×40 设计坐标（旧纹理实际以三倍分辨率绘制）缩至 24×20 像素网格，保留原来的透视立方体、宽右侧面、斜向顶面、深色边线和分别向外展开的底部折片。不是上一次的窄侧面箱子造型。穿戴仍使用同一像素图、原支点与左右翻转，画布宽高比恢复原来的 6:5。

`BombPickupItemVisual.GetBombRows` 与 `SamplePixel` 是拾取/背包和放置炸弹共用的图形与颜色定义。放置后的弹体/高光/引线分层保留，弹体按原定时闪红，引线与顶盖不跟随闪红。配置时依据保存的道具 ID 选普通或超级外形，重新配置和销毁时释放旧纹理。

未修改世界缩放、碰撞体、费用、引爆时间、爆炸伤害/范围、纸箱穿戴和容纳机制。

## 外壳与引线材料

超级炸弹外壳直接复用成品紫色弹体的像素布局，保留肩部、加强带、方形扣件与底部块面；去掉已安装的金属顶盖和引线，在顶部增加未装配的深色接口。独立图标向上居中两像素。阴影颜色与成品一致，保留外壳自身可编辑颜色字段。

独立引线改为 16×16 的连续粗像素折弯绳，采用与成品一致的浅棕主色、深棕侧边和少量橙色末端。材料背包图标与地面视觉共用图案，仅同步预制体的阴影/引线颜色，不修改任务提交、道具 ID 或使用逻辑。

`Docs/BombMaterials-preview.png` 对照外壳、引线和成品超级炸弹。测试额外覆盖两种材料的 16×16 尺寸、轮廓连通性以及外壳与成品弹体的逐像素一致性。

运行 `Tools/TestBombAndBoxVisuals.ps1` 检查实际绘图方法：像素图尺寸、纸箱 6:5 比例、轮廓连通、Point 采样、普通/超级炸弹有无高光时拾取与放置层合成一致、纸箱拾取与穿戴颜色一致。共 1504 次逐像素比较。预览为 `Docs/BombAndBox-preview.png`，不含 CRT 和动态粒子；Unity 游戏内效果仍需实际验收。
