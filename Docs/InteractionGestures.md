# 交互伸手与前方放置

- 玩家成功操作拉杆、水闸控制器，或使用普通消耗道具时，沿当前面朝方向播放约 0.24 秒伸手动作。复用 `ZeldaFourWayMover.TryBeginItemAttack`，不生成近战武器、伤害框或攻击音效；不能攻击的平民也可伸手。
- 所有物品成功拾取时也播放相同动作，包括纸箱、稳定结晶和手铳（“不加动作”的例外只适用于使用，不适用于拾取）。在公共成功拾取通知中接入，先伸手再打开首次拾取说明；拾取失败不播放，已有攻击/伸手姿态不会被打断或重新计时。已部署机关人偶成功收回背包也覆盖。
- 纸箱与稳定结晶保留原有使用表现；手铳沿用现有出手/枪口动画，不叠加第二次动作。工匠使用已有无锤子的出手帧。
- 人偶遥控器为可重复使用物品，因此在其使用回调中触发动作，不以是否消耗道具判断。没有 R 效果的钥匙、任务材料等不播放无效动作。魔力电池通过 E 成功安装/卸下时也会伸手。
- 拉杆权限不足、控制器断电/过渡锁定、背包转移失败时不播放成功动作；已有攻击/伸手期间不重复执行普通道具或开关操作。机关人偶自动拉杆和外部脚本操作不让玩家伸手。
- 炸弹（含超级炸弹）、机关人偶通过 R 部署时，生成点向当前面朝方向偏移 0.65 世界单位。武装魔像的 R/Q 放置使用相同规则，在恢复其存档缩放后按真实碰撞体尺寸检测。
- 放置时对整个路径做矩形扫掠并检查终点重叠，包含实体障碍以及 Blocks / Hidden Blocks 的触发器墙；忽略自身、临时道具实例、其他场景及普通交互触发区域。目标或路径受阻时，**直接回退到角色当前位置**，不寻找其他位置或取消使用。
- 普通 Q 丢弃物品不属于“放置来使用”，位置和行为不变。纸箱内部自动释放、炸弹受击爆炸与存档恢复调用的直接生成接口也不加前方偏移。
- 控制权丢失/组件禁用时结束道具姿态，眩晕时清除姿态标记。消耗、堆叠、电量和人偶状态保存规则不变。

## 验证

`Tools/TestInteractionGestures.ps1` 检查生产使用、伸手、拉杆、四向放置及阻挡过滤；物理命中结果采用替身，不替代 Unity 实机测试。另回归手铳动作、武装魔像 R/Q/存档、水闸控制器、电池槽、遥控器、炸弹音效及手铳堆叠。
