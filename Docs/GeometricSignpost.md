# 极简指路牌

将 `Assets/Prefabs/Decorations/GeometricSignpost.prefab` 拖入场景即可使用，未自动放入场景。

一根单色棕色立杆配三块纯色箭头牌板，自上而下朝左、右、左，无木纹、铆钉、文字或描边。与路灯、几何树一样使用平面几何，四块几何合并为一个 MeshRenderer。

默认高 3.2、宽 1.16，杆宽 0.18，牌板高 0.24、间距 0.14。牌板宽高均缩小 20%，立杆尺寸不变；外露杆高 2.2，占整体约 69%，突出细长立杆。Inspector 支持调整尺寸、颜色、首块箭头方向；之后的牌板自动交错。为维持杆部为主，编辑尺寸时总高不会低于牌板区域高度的两倍。

原点在杆底。底部实体碰撞为 0.18 × 0.22，可通过 Solid Base 关闭；上方不阻挡移动，以默认排序 5 遮挡角色。无需使用 Blocks 层。颜色与高度均可在 Inspector 调整。编辑器可预览，仅参数变化时重建几何。
