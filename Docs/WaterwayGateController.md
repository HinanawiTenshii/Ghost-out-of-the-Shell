# 水闸控制器

预制体：`Assets/Prefabs/Decorations/WaterwayGateController.prefab`

## 使用

1. 将控制器预制体拖入场景，放在需要操作水闸的位置。
2. 在 `Waterway Gate Controller > Binding / 绑定水闸 > Linked Gate` 中拖入场景内目标水闸的 `WaterwayGate` 组件。
3. 编号窗口自动显示该水闸的编号（如 1A、2B）；修改水闸上的 Number / Letter 后会自动同步，无需手动录入第二份编号。
4. 控制活着的实体角色，靠近并面向控制器，按 E 开启或关闭绑定水闸。默认交互距离 1.4，可在编辑器调整。

预制体资源本身不引用某个场景中的水闸；请在放入场景后的实例上绑定。未绑定时窗口显示 `--`，不提供交互，不会报空引用错误。未对现有场景自动添加实例。

## 外观与状态

- 灰色金属盒、深色小窗口、红色电闸手柄，使用与水闸一致的简单矩形几何和项目像素字体。
- 编号橙色表示关闭请求，绿色表示开启请求；拉杆以槽中心为固定转轴，上为开启、下为关闭，约 0.16 秒切换。显示的是水闸的目标开关状态，而非声称闸板动画已经完成。
- 当绑定的电池槽为空或剩余电量为 0 时，编号统一显示浅灰色（RGB 0.76 / 0.78 / 0.80），保留原有编号内容；安装有电电池或恢复供电后，恢复上述绿色／橙色。复用现有 `HasBatteryPower` 判断，多个电池槽绑定同一控制器时任意一槽无电即视为断电；未绑定电池槽的控制器维持原样。编号颜色随 Update 刷新，不重建几何或消耗电量；未绑定水闸时仍显示原来的灰色 `--`。
- 转轴固定在本地 `(0, -0.14)`，杆长 0.22，模拟绕水平轴从 -55° 到 +55° 的上下翻转。握柄采用圆弧运动的正交投影；杆身始终连接转轴和握柄，经过正面时投影缩短，握柄的可见厚度增加并遮住中心转轴。不是整根拉杆沿直线滑动，也不是绕画面法线左右摆动。
- 视觉只使用两个合批几何网格（盒体含固定轴座共 14 个矩形、手柄 6 个矩形）和一个编号 TextMesh；静态几何不逐帧重建。手柄仅在姿态改变时复用数组更新顶点，不新建材质或几何对象。
- 本体 0.86 × 1.24 世界单位，中心为父对象原点；预制体带同尺寸实心碰撞箱，使用 `Default` 层，受视野遮罩覆盖但不阻挡视线。视觉重建时会迁移旧场景实例的 `Visible Non Blocking` 层覆盖，包含外壳、杆部与编号窗口；交互提示仍沿用原有 UI 显示规则。
- 多个控制器可绑定同一水闸，或由其他机关控制水闸；所有控制器都以水闸状态为准，不单独维护易失配的开关布尔值。

## 控制接口与兼容

- `BindGate(WaterwayGate gate)`：运行时绑定或解除绑定；无电时新绑定水闸会按下述断电规则复位。
- `SetOpen(bool value)`：设置绑定水闸的目标状态。
- `ToggleFromExternal()`：供其他脚本或 UnityEvent 切换绑定水闸。
- `LinkedGate`、`DisplayedIdentifier`、`IsOpenRequested`：只读状态。

通过现有 `ZeldaInteractionArbiter` 提交交互，一次 E 仅由选中的交互对象处理；菜单、暂停、人偶接管输入、幽灵形态、死亡、超出距离或不同游戏场景均不会触发玩家交互。临时关闭/重新启用控制器不会重新定义水闸的初始状态。

## 断电复位

- 绑定的电池被取出、耗尽、炸毁或吞噬后，控制器手柄与水闸回到该水闸在场景中配置的初始 `Open` 状态（不是一律关闭，也不是上次操作前的状态）。
- 复位沿用原有水闸动画与开启／关闭完成事件，因此原有单闸、双闸供水条件和水域淡入淡出继续生效。即便正在开关或水域渐变，断电也能触发复位；普通交互仍受原有锁定约束。
- 初始状态在第一次运行时启用或修改前记录，距离卸载与再次启用不会覆盖。没有新增场景配置字段，也不修改已有场景或扩展存档格式。
- 重新供电只恢复可操作状态，不会自动恢复断电前的操作。背包已满导致卸下电池失败时不会复位；电池槽被距离卸载也不算断电。普通拉杆保持原逻辑，水闸正常操作仍不耗电。
- 电池槽在状态改变时通知控制器，无新增逐帧扫描。

没有修改 WaterwayGate 的动画、碰撞及完成事件：关闸开始前阻挡通道，开闸动画完成后才释放通道。也没有修改普通门或拉杆。存档持久化仍遵循原水闸能力，本次未扩展存档格式。
