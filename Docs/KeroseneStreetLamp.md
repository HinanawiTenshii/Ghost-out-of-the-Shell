# 煤油路灯

预制体：`Assets/Prefabs/Decorations/KeroseneStreetLamp.prefab`。

拖入场景即可使用。根节点原点在底座底部，默认高 3.2 世界单位。极简版本仅用五块平面几何组成：矩形底座、直灯杆、梯形外框、整块暖黄玻璃、单层梯形灯帽。移除了横杆、金属高光、底座层级、窗格、灯芯和顶端装饰；不是像素贴图。编辑器中可预览静态外形，运行后光晕呼吸。

`KeroseneStreetLamp` 组件提供统一金属色、玻璃颜色，内外光晕半径和颜色（Alpha 决定亮度）、光晕中心、呼吸周期及半径/透明度振幅。双层呼吸光效保持原有参数：默认 3.2 秒一周期，半径上下变化 8%，透明度上下变化 18%。每盏灯错开起始相位，暂停时停止呼吸。通过根节点等比缩放调整整体大小；非等比缩放会让圆形光晕变成椭圆。

`Light On` 或 `SetLightOn(bool)` 控制光晕开关。关闭光晕不改变玻璃本身的颜色。`Sorting Layer Name` 与 `Sorting Order` 调整整体排序；外圈、内圈、灯体依次递增，灯体始终位于自身光晕之前。

光效是正常透明混合的两层淡黄色圆形，圆边缘轻微柔化，可以随场景一同经过 CRT 滤镜；不依赖额外 2D 灯光管线，不修改主摄像机、视野半径或任何场景文件，也不照亮或揭露视野盲区。

底座自带非触发器 `BoxCollider2D`：本地尺寸 `(0.42, 0.22)`、中心偏移 `(0, 0.11)`，恰好覆盖矩形底座；随根节点缩放、旋转。灯杆、灯罩和光晕均无碰撞，角色可以从这些部位经过。灯体绘制顺序默认 5，最低 2，高于当前角色的 1，因此上部灯体遮挡经过的角色；仍使用正常世界渲染，不改为穿透视野的屏幕叠加层。保持 Default 层即可，不需要改成 Blocks。脚本重建会同步底座碰撞尺寸，避免新增组件默认碰撞覆盖整盏灯。

几何体在启用时生成，编辑器隐藏的生成对象和网格不会保存进场景；运行时常态仅调整两层光晕的缩放与颜色，不每帧生成网格或材质。生成资源随组件销毁释放。
