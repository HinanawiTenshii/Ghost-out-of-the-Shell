# 沙漠城市滤镜

在主摄像机添加 `Rendering → Desert City Screen Effect`。
建议停用原来的 `Desert Screen Effect`，保留 CRT。新组件可以独立使用，也已接入 CRT 最终合成：先做城市调色，再做 CRT，无需添加到 UI/Blocks 摄像机。

使用淡米黄高光与浅暖沙色中间调，默认强度 0.45、原色保护 0.9、去饱和 0.06、薄雾 0.025。大部分源颜色保留，鲜明的红、绿、蓝与亮色物体受到更小影响；黑色视野遮罩保持黑色。颜色保护按像素亮度与色差判断，不是语义物体遮罩。

- `Intensity`：整体强度；设为 0 旁路。
- `Object Color Preservation`：越高越保留明亮、鲜明物体的原色。
- `Shadow / Midtone / Highlight Color`：暗部、中间调与高光沙色。
- `Desaturation`：轻度去饱和；0 不去饱和。
- `Haze`：静态、非常轻的暖色薄雾；0 关闭。
- `Preview In Editor`：Game 视图编辑预览。

专用 Shader **没有扬沙粒子、风场、动态颗粒噪声或动画时间计算**，并非只把旧粒子透明度设为 0。单次采样、单个全屏 pass；原有 CRT 的扫描线与噪声仍由 CRT 控制。

如果同一摄像机同时启用新旧沙漠组件，城市版优先，避免旧版再次染色或叠加扬沙（有无 CRT 均如此）。停用城市版后原版恢复。与水光滤镜同时启用时，沿用先调色、再水光、最后 CRT 的顺序。

原沙漠滤镜的参数和 Shader 未修改，没有自动挂载或改动现有场景。此效果针对项目的 Built-in 渲染管线。
