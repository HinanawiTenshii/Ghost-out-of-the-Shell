# Chest 风格货架与横置大型酒桶

新增预制体位于 `Assets/Prefabs/Decorations/`：

- `StorageRack.prefab`：与 Chest 一致的俯视木货架，默认 2.8×2.5；只展示顶层置物台、三件箱货的箱盖与四角立柱端面，不展示侧视层板、垂直立柱及下层货物。
- `Barrel-Horizontal-Large.prefab`：横向桶轴的俯视大型酒桶，默认 3.4×1.9；两端收窄的八边形桶身、顶部亮面、两道灰色桶箍与顶部方形桶塞。不展示端面或底部支架，轮廓上下对称。

沿用 Chest 的主体褐色 `(0.67,0.39,0.2)`、深边 `(0.38,0.2,0.11)`、灰色金属 `(0.67,0.71,0.74)`，以大面积色块表示木材明暗，不加细碎木纹、铆钉或像素噪点。

两个根节点位置归零，原点位于完整外观中心。`Geometric Storage Furniture` 组件可修改 Size、木色、边色、亮面、金属色、Solid 和排序。使用引擎 Sprites/Default 材质，不生成贴图，每个预制体仅一个 MeshRenderer；货架 76 个顶点，酒桶 60 个顶点。保留原预制体 GUID 和尺寸，已有实例会沿用新外观。

碰撞随 Size 更新：货架为整体矩形阻挡；酒桶沿俯视桶身的八边形轮廓阻挡，切角保持空白。Default 层，与原 Chest 一致，不额外遮挡视野。编辑器中可见，网格仅在启用或参数变更时生成。

不包含物品存储、开关或其他交互，未放入场景；原 Chest 和 Shelf 不作修改。

`Tools/TestStorageFurniture.ps1` 提取正式几何构造校验形状、中心、凸面三角化和预制体碰撞，并生成与 Chest 同比例的预览。另做 Unity API 编译，尚未进行游戏内 CRT 和碰撞实测。
