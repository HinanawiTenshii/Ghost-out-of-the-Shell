# Strongman / Blacksmith 锤形攻击重绘

共用 `ZeldaAttackHitbox.Hammer` 的 Strongman、Blacksmith 及沙漠关卡衍生角色自动使用新的攻击锤子，不需要重新绑定预制体。

- 16×16、16 PPU、Point 采样，与当前 SwordGuy 使用相同像素密度和四级中性明暗色。
- 宽厚金属锤头、整块上缘亮面、深色侧端与下缘、连接箍、粗握柄和尾端。没有裂纹、铆钉或细碎缠带。
- 使用 SwordGuy 原有颜色映射，并保留角色自己的攻击 Tint，包括 Strongman 的暖色和工匠的灰蓝色。
- 原锤子 12×12 / 12 PPU 的 1×1 世界尺寸与 `(0.5, 0.2)` 握柄枢轴不变；新图分辨率提高不改变攻击范围、偏移、四向旋转、持续时间或伤害。
- 没有更改角色身体、手部或工匠身上的锤子装饰。剑、书、岩石和冲击波不受影响。

`Tools/TestHammerAttackVisual.ps1` 校验像素、颜色、连通性及接入，并从正式像素表生成预览。Unity 编译及剑视觉回归另行检查；预览不等同于游戏内 CRT 渲染。
