# 电门柱

预制体：`Assets/Prefabs/Decorations/ElectricGatePillar.prefab`。

## 场景配置

- 俯视红灰金属柱，六块矩形主体；可选面板增加三块小矩形。柱体有 1×1 碰撞箱。电流不使用阻挡所有人的实体碰撞箱。
- 放两根柱子，中心距离不超过 10，之间没有墙或关闭的门。每根柱子选择最近可见的另一根，相互选择只生成一条电流。在多柱布局中，一根柱子可以被其他柱子选择，但同一对永远只有一条线；建议成对布置以保持直观。
- Inspector 的“安装控制面板”和“面板所在面”控制有无面板及上下左右位置。旋转、镜像和缩放后接线位置仍跟随面板所在面。
- 把带面板的整个电门柱对象（或其 `ElectricGatePillar` 组件）拖入电池槽的 `Linked Mechanism`。绑定时自动识别同一对象上的功能组件，避免 Unity 优先选择视觉脚本导致绑定被清空；不搜索其他父子对象，无面板柱子仍不能绑定。电缆自动从电池槽本地底部连接到面板面，复用现有直角寻路、设备避让和线路避让。
- 未连接电池槽时无需电源；连接后，必须装有剩余电量大于 0 的魔力电池。无面板接收柱不额外限制带面板柱子的通行规则。
- 两端都有面板时，两端规则均须满足，两端所绑定的电池槽均须有电。每次触发对每个相关电池槽各扣一格；单面板常规配置只扣该电池一格。已有水闸、拉杆不新增自动耗电。
- 两端都无面板时使用 Inspector 中的默认规则（默认最低权限 3）；可在 Inspector 调整权限，但不提供游戏内配置入口。

## 游戏内设置

活着的非幽灵角色靠近面板按 E，打开与现有密码锁一致的 CRT 配色、像素字体界面。设置时暂停游戏。

- **权限通过**：选择最低权限（-2 至 9），角色权限大于等于该值即可通过；支持按钮和方向键调整。
- **个体通过**：点击“登记当前角色”，登记当前肉身的独立身份；换人控制不会改变登记。只登记一个角色，再次登记会替换。清除后无人通过。
- E / 保存按钮提交，Esc / 取消按钮放弃草稿。面板设置与角色独立身份进入既有存档与跨场景状态，旧存档无新增字段时使用预制体默认配置。

## 电流与伤害

- 电流沿双柱连线形成宽 0.5 的红色锯齿细流与短寿命粒子。未获许可角色接近约 0.8 单位的预警区时增加电流支线和粒子数量；角色体积也纳入判定。
- 电流与电击使用局部加法泛光：红色柔和光晕、偏白的亮芯，粒子径向衰减，电击在原有 0.25 秒内渐暗。光晕可延伸到区域外，但实际生成中心、伤害与幽灵阻挡范围不变。不修改全局 CRT、不额外添加渲染器或全屏后处理，仍受视野遮罩遮盖。两份共享材质在网络销毁时释放，着色器通过 Resources 保留到构建中。
- 未获许可角色进入时，先完成电池扣电事务，再从双柱各产生一道放电弧，各调用一次 8 点基础伤害（沿用角色现有受伤/防护规则）。第一击致死时不再对死者重复调用伤害，但双端放电视觉仍保留。
- 每个进入事件只扣一次电，不因两道攻击重复扣电。停留在电流中不会每帧重复触发；离开后再次进入可重新触发。快速跨越也会通过扫掠检测被识别。
- 耗尽最后一格电后立即断电，最后一次放电弧仍显示 0.25 秒。卸下或炸毁电池也会断电。
- 幽灵不触发预警、不受电流伤害；活跃电流区域仍阻挡其正常移动。电门杀死受控角色时，新幽灵沿连线法向回到入场侧约 0.95 单位处（遇墙缩短），不依赖当前控制者的朝向。
- 电流、柱体使用普通世界渲染层，受现有视野遮罩遮盖。柱子和网络保留逻辑运行；摄像机卸载的矩形墙仍参加直线遮挡检查。

## 指示灯与允许通行提示

柱体上方原本的红色导体与亮色顶条现在是状态指示灯，钢制外壳和底部银色条不变。运行时同一条电门的两端同步显示：

- **未形成有效通电连接／断电**：深灰色灯芯，比周围灰色金属更深，无光晕。无面板接收柱随另一端断电，不会因为自身无需电池而继续亮红。
- **正常通电**：保留原来的红色灯芯，附带暖红色呼吸光晕，默认周期 2.8 秒、强度在基准的 76%–124% 之间。
- **允许通行角色靠近**：两端灯芯、顶条、光晕，以及连接区域的电流和粒子变为天蓝色。沿用原预警接近范围（电流条带外约 0.8 单位，再考虑角色体积），离开后恢复红色。只有颜色改变，保持一条普通电流及普通粒子数量/大小，不增加警告支线、不播放警告层音效、不扣电或攻击。
- **未获许可角色靠近**：保留原本红色警告、增多的电流和粒子，以及警告音效、入场伤害规则。允许与禁止角色同时靠近时，禁止角色的红色警告优先，避免蓝色错误暗示任何人均能通过。

允许状态复用电门真实通行判定，支持权限大于等于门槛和“个体通过”登记，两端都有面板时须同时满足；活着的 NPC 与受控角色使用相同规则。幽灵、死者或其他场景的角色不会触发蓝色。
一个柱子连接多条线路时，灯色优先级为警告红 > 通行蓝 > 待机红 > 断电灰；各条线路仍保留自己的通行和伤害判断。
网络在本次所有扣电事务完成后发布指示灯状态，防止另一条线路消耗最后一格电后接收柱仍亮着。未绑定电池槽时无需外部电源的旧规则保持不变；单独放置未连线的柱子不会点亮。

视觉组件增加“指示灯光晕强度”和“指示灯呼吸周期”，光晕强度 0 可关闭光晕但保留灯色。各端采用同一游戏时间同步呼吸，暂停冻结。非运行编辑状态显示未通电灰色；动态供电和通行指示在运行时生效。

### 灯面权限数字

处于“权限通过”模式的电门柱在灯芯中央显示自身设定的最低权限（-2～9，包括负号）；“个体通过”模式隐藏数字。数字直接读取 `ElectricGatePillar` 当前配置，Inspector 修改、游戏内面板保存和存档恢复后均自动刷新；取消面板草稿不影响已显示的等级。不新增存档字段，也不修改任一端的实际通行规则。

数字使用与简单几何体风格一致的 3×5 像素格点，而非悬浮 UI。颜色由当前警示灯颜色向白色提亮 48%：红灯显示浅红数字，允许通行的天蓝灯显示浅天蓝数字，断电显示浅灰数字。数字本身不额外泛光、不跟随呼吸闪动，以保持可读性；现有灯晕保留。负数整体缩小并居中，不覆盖灯帽。显示随柱体变换，处于普通世界渲染层并受视野遮罩遮盖。

每柱增加一个至多 80 顶点的小网格和一个 Renderer，不逐像素创建对象；仅等级变化时更新网格，停用与销毁释放网格和材质。已有场景和预制体自动生效，无需重新摆放。
每柱额外一个四顶点软光晕网格，复用 WarmLightGlow 着色器、独立实例材质；没有新增碰撞或全屏后处理，仍位于普通世界层、受视野遮罩覆盖。停止/销毁时释放光晕网格和材质。
电流着色器的亮芯改为由输入颜色向白色提亮，避免原本固定暖色亮芯使蓝色粒子偏红；攻击放电仍保持红色。

## 验证

- `Tools/ElectricGate.Validation.targets`：包含新脚本的完整 C# 编译。
- `Tools/TestElectricGate.ps1`：执行实际几何、权限与放电方法，测试旋转、快速穿越、幽灵双向阻挡/脱离、入场侧回弹上下文，并核对存档与 UI 集成。
- `Tools/TestBatterySocket.ps1`：包含双端事务原子性、仅扣一次、最后一格断电、无面板拒绝绑定等检查。
- `Tools/TestBatterySocketCable.ps1`：原有寻路回归与四面板方向/旋转/缩放的接口路由检查。
- `Tools/TestElectricGateSignals.ps1`：执行实际 Field.Tick、两端状态发布、灯色与呼吸方法，覆盖授权/拒绝混合、个体登记、幽灵排除、同等粒子密度、警告声音、末格扣电和双端同步。
- `Tools/ElectricGatePermissionLabelSmoke.cs`：在隔离 Unity 工程使用生产组件，覆盖全部 12 个等级、负号、两种模式、存档/Inspector 更新、灯色、几何边界、原碰撞不变、资源释放及 GPU 遮罩/可读性；生成 `Docs/ElectricGatePermission-preview.png`。
- `Tools/ElectricGateSignalSmoke.cs`：在隔离 Unity 工程中使用生产视觉组件与两个生产着色器进行 GPU 渲染；灯色、软光晕和蓝色电流材质采样通过（红灯 6086 个红色主导像素，蓝灯 9093 个蓝色主导像素，无错色；灰灯中心无发亮像素）。隔离工程仅用小型柱体/状态桩提供静态状态，动态行为由上面的实际 Tick 方法测试覆盖；该脚本不挂载到正式关卡。

逻辑桩测试、项目编译和独立 GPU 材质检查均通过，不等同实际关卡的 Unity Play Mode 验收。仍需在编辑器实际摆放两柱、电池槽及一堵墙，观察 CRT 滤镜下的电流、菜单字体、遮罩、声音与角色死亡后的实际衔接。
