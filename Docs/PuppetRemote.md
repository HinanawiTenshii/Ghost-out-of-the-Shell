# 人偶遥控器

预制体：`Assets/Resources/PickupItems/PuppetRemotePickupItem.prefab`，物品 ID：`puppet_remote`。

灰钢外壳、红色装甲分块与中央红色开关、短天线，16×16 点采样像素造型。无窗口或蓝色指示灯，灰色/高光/阴影/红色沿用自动人偶的装甲与能量配色。沿用道具拾取呼吸效果与库存图标系统。

说明原文：用于控制人偶的遥控器，使用可以开启或关闭附近的人偶，注意：人偶索敌系统存在故障，会攻击附近所有的人。

- 放入场景后，靠近按 E 拾取，选中物品栏槽位按 R 使用，按 Q 丢弃；可反复使用，不消耗。
- 按请求以使用者所在的游戏场景为范围，不增加半径或视线限制。说明中的“附近”不另行解析为距离限制。
- 每个目标分别反转其持久化激活标记：待机变敌对、敌对变待机。混合状态时不会强制统一开关。
- 只处理 `AutomatonCharacterAi`（自动人偶 / 武装魔像），不影响负责操作拉杆的噬菌体形机关道具。
- 仅处理对象和 AI 组件均启用、存活、非幽灵的目标；禁用、视野加载系统卸载、其他场景及库存中的人偶不受影响。不主动加载远处对象。
- 玩家附身但 AI 组件仍启用的人偶也更新激活标记，不会夺走玩家控制；解除控制后遵循该标记。
- 使用现有 `SetHostilityActive` 接口，停机取消攻击，视野红蓝状态及存档继续沿用现有逻辑。眩晕不被遥控器移除。
- 不会因靠近纸箱将 R 变成收纳；人在纸箱内时仍沿用全局的 R 先退出纸箱规则。
- 成功提示受影响数量，无目标时提示但仍保留道具。未向任何场景自动放置物品。

检查：`Tools/TestPuppetRemote.ps1` 执行完整道具代码的作用域/激活切换/非消耗测试及像素布局检查，Unity 引擎服务由测试桩替代。项目编译使用 `Tools/PuppetRemote.Validation.targets`。仍需 Unity 内验证拾取、使用、丢弃、存档及实际渲染。
