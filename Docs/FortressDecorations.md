直接拖入地图使用。保持现有装饰的严格俯视视角与简单几何风格，不绘制侧立桌腿、井壁立面或正面火焰。
木材为褐色，石材及铁器为灰色，水面、余烬及符文使用少量高饱和强调色。

根对象的 Geometric Fortress Decoration 可编辑 Size、Wood Color、Metal Color、Accent Color、Solid、Sorting Order。
允许 Z 轴旋转或 Transform 缩放，几何及碰撞一起变换。符文阵默认不挡路；其他五件采用简单包围盒碰撞，可按布景需要关闭 Solid。

除弩炮外均为纯装饰：符文阵无机关效果，火盆无伤害。弩炮现已支持尾部按 E 发射爆炸箭矢，详见 `Docs/FortressBallista.md`。未修改现有地图。

## 火焰与符文泛光

火盆中央原有五块红、橙、黄色火焰全部从静态主体中移出，改为一个 20 顶点的动态网格。每块使用接近正方形的四边形轮廓，宽高比维持在约 0.9–1.12，角度接近直角，仅保留轻微伸缩、剪切及转动，不再形成尖细三角或拉长的菱形。色块在俯视 XY 平面内活动，接近盆沿时整体等比例收敛。每块独立经历生成、展开、轻微变形、缩小和完全淡出；黄色中心也会消失，不留下固定底图。五组生命周期交错，每次重新生成时位置与轮廓有小幅变化；默认每块约 1.1–1.5 秒完成一个周期，火堆持续燃烧而不会同时熄灭。不形成侧视火柱。

另一个 113 顶点的泛光网格覆盖火焰软边及周围的暖橙色火光，强度轻微波动。每块火焰消散时，它的边缘光晕同步淡出；石台、木柴不变形。复用 WarmLightGlow 着色器，不添加真实光源或改变全局 CRT。Brazier 分组可调整「火焰变化速度」（默认 1.6）、「火光泛光强度」（1.8，0 关闭）和「火光扩散范围」（0.95）。火焰与泛光排序为 -2/-1，继承物体层，位于角色下方，并被后绘制的视野遮罩遮盖。

运行时还保留小型余焰 ParticleSystem，以盆中心半径 0.22 的区域发射正方形火星，黄橙到红色、缩小淡出。默认每秒 12 颗、寿命 0.55–0.9 秒、上限 32 颗，仅为中央动态火焰的补充。火焰、火光与火星随主体及 Size 变换；暂停游戏时冻结，停用时隐藏并清除粒子，销毁时释放生成资源。编辑器显示带泛光的静态生命周期预览；播放模式中才运行完整动画。固定顶点缓冲区复用，不逐帧创建网格、材质或 GameObject。

`Tools/BrazierFireSmoke.cs` 在隔离 Unity 工程中检查全部色块完整生灭、凸轮廓、火盆边界、光晕消散、遮罩覆盖、碰撞尺寸与资源释放，并生成真实渲染帧。动画预览为 `Docs/BrazierFire-preview.gif`，不含项目的最终 CRT 后处理。

符文强调色采用与电门一致的暖红 RGB (1, 0.14, 0.08)。额外单个泛光网格仅覆盖环形红纹、中心红色菱形边带和八段符号，灰石、金色点缀与浅色中心不作为发光源。
复用蜡烛/路灯的 WarmLightGlow 加法混合着色器，外围由顶点透明度形成软边，不调整全局 CRT 或后处理。发光仍按普通世界顺序绘制，位于角色之下、遵守项目视野遮罩的覆盖顺序。
Effects 中可编辑 Flame Rate、Rune Glow Intensity（0 关闭）与 Rune Glow Width。新增粒子网格、泛光网格和材质会在重建/销毁时清理。

符文泛光在游戏运行时按 3.2 秒周期平滑呼吸，强度在基础值的 65%–135% 间变化，不熄灭、不改变石台大小。Rune Breath Period 与 Rune Breath Depth 可调整周期和幅度，幅度为 0 时恢复恒定亮度。
金色版本是独立预制体，Accent Color 为 RGB (1, 0.68, 0.12)，主体魔纹、泛光和三种浮动符文均使用该颜色。尺寸、无碰撞、排序、呼吸周期与粒子数量均与红色版本一致，复用同一脚本和着色器，不影响原版或已有场景实例。拖入地图即可使用；预览见 `Docs/Fortress-RuneSeal-Gold-preview.png`，隔离 Unity 渲染检查入口为 `Tools/GoldenRuneSealSmoke.cs`。
符文阵周边的窄环形区域以每秒 2.5 颗随机浮现三种粗线条符号，寿命 1.4–2.2 秒、同时最多 16 颗。符号淡入、轻微漂移转动后淡出，每个符号自带软边泛光，与主体复用同一呼吸发光材质。
Rune Particle Rate 为 0 时关闭符文粒子。发光网格只在重建时生成，运行时仅更新材质亮度，粒子交由 ParticleSystem 处理；暂停时冻结，停用时清除，销毁时释放三个符号网格。
静态几何预览不包含呼吸动画和运行时粒子，实际 CRT 效果仍需在游戏内检查。

### 浮动符文蓝色问题修复

已保存的符文预制体为红色，Level2-Floor1 的实例也没有颜色覆盖。根因为 Unity 2021.3 的网格粒子将 Float32 网格顶点色当作 RGBA8 读取：红通道浮点 1.0 的字节 `00 00 80 3F` 被读成蓝色，而不是预期的红色。
CreateGlowMesh 现在明确写入 Color32，保留原有暖红配色、透明软边、生命周期淡出以及共享材质的呼吸效果。粒子显式设置 Position/Color/UV 顶点流，不修改全局滤镜或蜡烛、路灯着色器。

在独立 Unity 2021.3 渲染工程中复现并验证：旧版 BakeMesh 顶点色为 (0, 0, 0.502, 0.208)，修复后为 (1, 0.141, 0.078, 0.608)；修复后的渲染采样有 22086 个红色主导像素、0 个蓝色主导像素。测试不操作打开的地图场景。
`Tools/RuneParticleSmoke.cs` 为 Unity Editor GPU 验证入口：在隔离工程中包含当前 GeometricFortressDecoration 和 WarmLightGlow 着色器，把此测试放入 Assets/Editor，执行 `RuneParticleSmoke.Run`。生产项目不需要挂载测试脚本。

`Tools/TestFortressDecorations.ps1` 验证几何边界、三角形、顶点预算、序列化碰撞尺寸和组件引用，并由实际几何生成 `Docs/Fortress-preview.png`。该预览不是 Unity 实机截图。
编译验证使用 `Tools/FortressDecorations.Validation.targets`。
