# 巨兽视觉重绘

保留机械巨兽的 32×28 画布、16 PPU 和原支点。参考机械怪兽的块状结构重新设计：隆起的钢灰背甲、下沉的兽形面甲、黄色窄眼、金属獠牙、裸露红色活塞与厚重方拳。仍采用游戏当前清晰的像素块面，不复刻参考图的细碎纹理或等距透视。兽面嵌入躯干，不绘制脖子。

- 正面：高耸钢制肩块包围低伏兽面，窄眼和带獠牙的金属口部取代人形头盔/胸前核心。
- 头部轮廓：额甲上沿、两侧脸颊和收窄的下颌使用连续深色分界，搭配钢灰额缘与獠牙；侧面补齐面甲与背甲之间的暗边，保留无脖子的低伏体态。
- 背面：钢灰背甲、钢制散热脊柱与规则红色指示块，无眼睛和口部。
- 红色控制为规则矩形嵌块、方形指示灯和竖直活塞；移除大片红色覆盖及零散红边。每个待机朝向的红色像素占不透明像素比例不超过 20%。
- 侧面：后背隆起，兽形口部向前伸出；近侧巨拳覆盖身体中部，左右镜像。
- 腿部：由七行缩短为四行，位置 x=8..13 / 18..23，y=2..5；脚底仍在 y=2，落地高度与支点保持不变。
- 攻击：砸地时先移除待机手臂及活塞，重新绘制下压手臂与接地拳头；正背双拳、侧面可见近侧拳，眼部/背部散热结构对应变亮。
- 行走：更新巨兽在共享行走系统中的脚部范围，仍以原有 5 FPS 交替抬脚。

原有外观颜色字段保留，Inspector 运行时改色会刷新待机、攻击与行走缓存。预制体 XY 缩放从 1 提升至 1.25，视觉与碰撞体同比增大 25%；碰撞体本地尺寸保持不变，未缩放父节点下的实际尺寸为 1.8125×1.5625。场景已有实例无缩放覆盖，可继承此次改动。未修改角色属性、AI、攻击判定、恐惧咆哮、眩晕或摄像机震动逻辑；攻击范围的编辑器辅助线保持世界尺寸。

运行 Tools/TestBehemothVisuals.ps1，以真实绘图方法和行走变换检查四向待机、攻击、两帧行走，共 16 个姿态：尺寸、头肩连接、镜像、短腿、全身连通以及砸地接地。输出 Docs/Behemoth-Idle-preview.png、Behemoth-Attack-preview.png、Behemoth-Walk0-preview.png、Behemoth-Walk1-preview.png。

静态预览不含 CRT、运行时整体着色与伤害反馈，最终游戏内效果需在 Unity 确认。
