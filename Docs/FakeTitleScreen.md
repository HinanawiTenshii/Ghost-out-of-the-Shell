# AZURE QUEST 假标题界面

场景：`Assets/Scenes/FakeTitleScreen.unity`（沿用已有场景及其 GUID）。

## 表现

- 320×180 分层像素山峦与日出；按照概念样图采用深蓝天空、宝蓝与青蓝山峦，金色仅用于日出及地平线。独立的冰白至青蓝 AZURE QUEST 标题贴图，不带剑的装饰。4:3 画面的上下延伸区域使用同色系分档色带，与原背景边缘无色差衔接。
- 图像使用 Point 采样、不生成 Mipmap、不压缩；展示比例固定为 4:3，参考分辨率 1280×960。保留此前 1024×768 参考图的标题、菜单与山景比例；宽屏两侧、窄屏上下的多余区域由纯黑边覆盖，不拉伸画面。
- 菜单使用项目内的 ZLabs 12px 中文像素字体，放大三倍并带深色硬阴影。`FakeTitlePixelLabel` 固定以原生字号生成字形，避免高分辨率画布自动改用 18px 等非原生字号，造成笔画形状改变。专用 `FakeTitlePixelText` 材质按字体图集的像素中心采样、截断半透明边缘；菜单使用独立的 CRTCanvasBypass 画布，避免 CRT 色散与曲面重采样模糊文字。不修改共享字体图集或其他界面的采样设置。
- 普通文字青色、选中冰白、不可用项低亮度蓝灰色；星光与菜单指示使用青白色。选中时只改变文字与左侧指示，不点亮周围背景。
- 摄像机沿用项目的 CRT 渲染组件，本场景采用较轻的扫描线与辉光。仅本场景启用 `constrainAspectRatio`，将曲面、暗角与扫描线坐标限制于中央 4:3 显示区域；后置黑边不会被辉光或曲面染色。其他场景默认关闭该选项，沿用原先全屏坐标。
- 游戏启动时先保持全黑，等待现有场景载入结束后再停留 0.2 秒。随后背景、标题及 4:3 延伸区域直接切换五档预制调色板，每档保持 0.24 秒：少量深蓝色 → 宝蓝层次 → 青色与暗金色 → 浅青与明金色 → 原始完整配色。各颜色采用独立路径，日出先呈深蓝、随后转金，白色高光最后恢复；不是统一亮度乘算或半透明黑幕淡入。
- 五档播放时隐藏菜单与星光；完整配色保持后，只显示「按 ENTER 开始」，再过 0.12 秒启动低帧星光。标题亮起总时长约 1.52 秒（不含场景加载等待），全部使用非缩放时间。根对象的 `FakeTitleScreenPresentation` 可调整初始停留、每档停留和星光延迟。黑幕只在加载/最初停留期间完全遮盖，随后直接移除，无中间透明度。
- 等待界面中四个选项不可见且不可交互；Enter 提示每 0.65 秒在正常与较暗两档亮度间切换。按主键盘 Enter 或小键盘 Enter 后提示消失，四个选项从上到下分档亮起，每项为隐藏 → 深蓝 → 青蓝 → 原本颜色，共六步、每步 0.07 秒。全部显示且 Enter 松开后才开放导航，避免同一次按键直接确认第一个选项。继续游戏仍不可选；开场未结束时按 Enter 不会跳过演出。
- 标题附近的六处星光以约 6 FPS 轮流闪现，切换三张粗像素帧，不进行缩放/透明度插值；周期为 36 帧，每约 1 秒出现一次闪光（原为约 2 秒一次），每处六秒循环，无粒子模拟、无逐帧纹理生成。
- 编辑状态不显示黑幕，可直接编辑 Canvas；重新进入本场景时会重新渐亮。

## 选项状态

开始新游戏、游戏设置、退出游戏支持鼠标悬停和键盘上下选择；点击或按确认键时，文字与左侧指示闪烁三次后恢复（默认 0.08 秒一帧），不点亮底框。继续游戏禁用，键盘导航跳过它。

所有 Button 的 On Click 列表均留空。不接入新游戏流程、存读档、设置、退出，也不更改正式主菜单或 Build Settings。

## 标题音乐

已接入 Domi.wav 的 **Adventure's Spirit / Title Theme**（`Assets/BGMS/Domi/AdventuresSpirit.wav`）。场景中的 `LoopingBackgroundMusicPlayer` 使用 2D 循环、音量 0.18，不自动抢先播放；由标题演出在第一档调色板显示时启动。等待 Enter 和打开选项期间持续播放，不重新起曲；禁用标题或离开场景时停止。原始音频未剪辑或改动，保持流式导入。新手关的 **A Great Journey** 仍只暂存，不在本次接入范围。

## 操作音效

- 有效按下开头 Enter：`Assets/SoundEffect/FakeTitle/TitleEnter.wav`，约 0.28 秒的上行三音。
- 可用选项的鼠标左键确认或键盘确认：`TitleConfirm.wav`，约 0.14 秒的短双音，与选项闪烁同时开始；每次闪烁不重复发声。
- 两段均由 `Tools/GenerateFakeTitleAudio.py` 原创合成，使用柔化方波音色，44.1 kHz / PCM16 / mono，短包络避免硬切爆音。不使用第三方录音或提取游戏原声。
- 专用单音源为 2D、非循环、预加载，音量 0.3；与音乐音源分离，不打断 BGM。Unity 导入关闭归一化，保留原件受控峰值。音源播放中忽略重复请求，避免快速连点叠加或截断音符。
- 开场未结束、选项未显示、鼠标悬停/右键、禁用的继续游戏均不发声。禁用标题或退出场景时停止并清理音效。

## 维护与验证

- 运行脚本：`Assets/Scripts/UI/FakeTitleScreenPresentation.cs`、`FakeTitleMenuButton.cs`、`FakeTitlePixelLabel.cs`、`FakeTitleStarlight.cs`。
- 图片资源：`Assets/Art/UI/FakeTitle`。`*-PowerOn-1` 至 `*-PowerOn-4` 为离线生成的中间调色板贴图，最后一档复用原图；没有运行时纹理生成、逐像素计算或全局调色修改。精灵正常参与既有 CRT 渲染，独立菜单仍保持清晰。
- `Tools/BuildFakeTitleScreen.cs` 的 `Run` 是初次生成入口，仅允许在 `.codex-temp` 隔离 Unity 项目中运行，会覆盖生成的标题根对象。`Refine` 是局部迁移入口，保留内容布局，更新标题、独立菜单画布、星光与 4:3/CRT 设置。`Recolor` 更新配色并同步重建中间调色板。`UpgradePowerOn` 为调色板开场的局部迁移入口；`UpgradeEntry` 仅增加 Enter 提示、选项过渡绑定和标题音乐，不改既有布局或 CRT。显式色表位于 `PowerOnPalettes`。
- `Tools/FakeTitleScreenSmoke.cs` 验证五档贴图的轮廓与 Alpha 不变、跨图色表一致、日出色相由蓝转金、最终复用原图，以及菜单/星光依次出现、暂停时间仍正常播放、组件重启与场景重进。也保留 T 字连接、点阵材质、禁用选项、空事件、键鼠选中/闪烁、无亮色底框、鼠标显隐、4:3 黑边与 CRT 坐标，以及 1280×720、1920×1080、1024×768、1920×810、900×1200 布局检查；额外输出每档开场截图。

测试还覆盖 Enter 前选项锁定、提示分档闪动、重复打开拦截、逐项颜色过渡、打开选项不重播音乐、流式音频循环、重进不叠加音源；操作音效检查实际导入峰值、开头 Enter、鼠标与键盘确认、连点防重叠、禁用/悬停/右键静音以及离场清理。`UpgradeMenuSounds` 仅接入音效；`GenerateFakeTitleAudio.py --check` 可校验音频可复现性与电平。场景不需要运行时生成纹理、音频或界面对象；资源及布局均已经序列化。
